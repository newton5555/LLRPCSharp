04 / VIRTUAL DEVICE CLI SERVER

独立运行的虚拟读写器服务程序

LlrpVirtualDevice.Cli 是一个独立的虚拟 LLRP 读写器服务程序。无需编写一行代码，即可在任意机器上启动标准的 LLRP TCP 监听服务，支持丰富的生活化仿真预设与交互式动态标签注入，供任何标准 LLRP 客户端连接联调。

工具概览与特点

零代码独立运行

单行命令即可启动支持标准 5084 端口的完整读写器服务，随时为应用提供测试靶机。

预置丰富仿真场景

内置传送带 (Conveyor)、仓库货架 (Warehouse)、通道门禁 (Portal) 等典型物理场景。

交互式动态 REPL

支持在服务端运行中动态添加/移除标签、切换天线或调整射频抖动参数。

1. 一键启动服务 (run)

通过 run 命令直接启动 TCP 服务端并在前台保持监听： 

# 1. 默认启动（标准 1.0.1 协议，监听 0.0.0.0:5084）
dotnet run --project src/LlrpVirtualDevice.Cli -- run

# 2. 指定端口与 Impinj Speedway R420 档案
dotnet run --project src/LlrpVirtualDevice.Cli -- run --port 5084 --profile impinj.r420.llrp-1.0.1

# 3. 加载预设场景启动
dotnet run --project src/LlrpVirtualDevice.Cli -- run --preset warehouse

2. 预设仿真场景 (Presets)

内置典型业务场景，快速模拟真实的标签分布与运动特征：

场景名称 适用预设 场景模拟特征
warehouse 密集仓库货架 分布在 4 根天线下的多标签群，带微弱射频抖动
conveyor 产线传送带 模拟标签按指定周期依序穿过天线 1 → 天线 2
portal 门禁通道 双天线通道，模拟人员/叉车进出门禁时的短暂刷卡
single-tag 单标签基线 天线 1 固定 1 枚标签，用于基础读写与基线排查 
# 查看当前支持的所有预设场景列表
dotnet run --project src/LlrpVirtualDevice.Cli -- presets

3. 交互式 Live 终端 (live / shell)

进入交互式 Live 终端后，可以在读写器运行期间动态观测客户端连接并注入标签事件： 

# 启动带有交互控制台的虚拟设备服务
dotnet run --project src/LlrpVirtualDevice.Cli -- live --preset warehouse

# 在控制台中动态注入标签：
> tag add E280119100000000000000FF --antenna 1 --rssi -50.0
> tag remove E280119100000000000000FF

# 查看当前连接的客户端与活跃 ROSpec 实况：
> status
> clients

4. 使用 JSON 配置文件定义虚拟设备

你可以编写结构化的 JSON 配置文件，定制天线数、硬件能力与模拟标签列表： 

{
  "server": {
    "listenAddress": "0.0.0.0",
    "port": 5084,
    "clientConnectionTimeoutSeconds": 30
  },
  "device": {
    "profile": "impinj.r420.llrp-1.0.1",
    "antennaCount": 4,
    "rssiJitterDb": 1.0,
    "tags": [
      {
        "epcHex": "E28011910000000000000001",
        "tidHex": "E28011052000600123456789",
        "antennaId": 1,
        "baseRssi": -55.0
      },
      {
        "epcHex": "E28011910000000000000002",
        "antennaId": 2,
        "baseRssi": -62.0
      }
    ]
  }
}
# 启动指定配置文件的虚拟读写器
dotnet run --project src/LlrpVirtualDevice.Cli -- run --config ./my-virtual-reader.json

5. 配置校验与能力查询

在启动前校验 JSON 格式合法性，或查看内置能力档案的详细参数： 

# 校验配置文件是否合规
dotnet run --project src/LlrpVirtualDevice.Cli -- validate ./my-virtual-reader.json

# 查询支持的能力 Profile
dotnet run --project src/LlrpVirtualDevice.Cli -- caps

6. 与第三方客户端生态互操作

虚拟读写器完全遵循标准 LLRP 协议实现，可直接接受各类外部客户端连接：

  • Impinj ItemTest：选用 impinj.r420.llrp-1.0.1 档案后，可直接在 ItemTest 中添加并扫描标签。
  • Java / Python / Go LLRP 客户端：如 ltkjava、libltk-d、pylogix 等。
  • LLRPCSharp 本项目 LlrpSdk 与 LlrpCli：无缝开箱即用。
