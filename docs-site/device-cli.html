04 / VIRTUAL DEVICE CLI SERVER

独立运行的虚拟读写器服务程序

LlrpVirtualDevice.Cli 是一个独立的虚拟 LLRP 读写器服务程序。无需编写业务代码，即可启动确定性软件 LLRP TCP 服务，选择内置协议/profile 预设、加载 JSON 标签数据，并通过交互式 Shell 管理宿主生命周期。

工具概览与特点

零代码独立运行

单行命令即可启动支持标准 5084 端口的完整读写器服务，随时为应用提供测试靶机。

预置丰富仿真场景

内置标准 1.0.1、严格 1.0.1、1.1、2.0 与 Impinj R420-shaped profile 预设。

交互式动态 REPL

支持在服务端运行中查看状态、控制启停/重启、切换日志以及观察 LLRP RX/TX 事件。

1. 一键启动服务 (run)

通过 run 命令直接启动 TCP 服务端并在前台保持监听： 

# 1. 默认启动（标准 1.0.1 协议，监听 127.0.0.1:5084）
dotnet run --project src/LlrpVirtualDevice.Cli -- run

# 2. 指定端口与 Impinj Speedway R420 档案
dotnet run --project src/LlrpVirtualDevice.Cli -- run --port 5084 --preset impinj.r420.basic

# 3. 显式选择 LLRP 2.0 软件预设
dotnet run --project src/LlrpVirtualDevice.Cli -- run --preset llrp.standard20.basic

2. 预设仿真场景 (Presets)

内置的是协议/profile 预设，用于快速复现版本、严格校验和厂商扩展路径；它们不是物理射频场景：

预设 ID 协议 用途
llrp.standard101.basic LLRP 1.0.1 标准协议和确定性标签报告基线
llrp.standard101.strict LLRP 1.0.1 启用严格标准盘点校验
llrp.standard11.basic LLRP 1.1 显式版本协商和 1.1 报文路径
llrp.standard20.basic LLRP 2.0 当前 2.0 translated device profile 基线
impinj.r420.basic Impinj R420-shaped / 1.0.1 Impinj 扩展激活和捕获默认值的软件联调 profile 
# 查看当前支持的所有预设场景列表
dotnet run --project src/LlrpVirtualDevice.Cli -- presets

3. 交互式 Live 终端 (live / shell)

进入交互式 Live 终端后，可以在读写器运行期间控制宿主生命周期、查看客户端连接和观察 LLRP 事件： 

# 启动带有交互控制台的虚拟设备服务
dotnet run --project src/LlrpVirtualDevice.Cli -- live --preset llrp.standard101.basic

# 在控制台中查看状态、事件日志并重启同一实例：
> server status
> logs on
> server restart
> server stop
> server start

4. 使用 JSON 配置文件定义虚拟设备

你可以编写 CLI 支持的 schema 1 JSON 配置文件，定制 profile、协议版本、报告节奏、确定性场景与标签列表： 

{
  "schemaVersion": 1,
  "presetId": "impinj.r420.basic",
  "capabilityProfileId": "impinj.r420.llrp-1.0.1",
  "protocolVersion": "1.0.1",
  "reportIntervalMilliseconds": 100,
  "reportCount": 0,
  "repeat": true,
  "rfScenario": "noisy",
  "randomSeed": 2026,
  "rssiJitterDb": 1,
  "tags": [
    {
      "epc": "E28011910000000000000001",
      "tid": "E28011052000600123456789",
      "peakRssi": -55,
      "antennaId": 1,
      "userMemory": [51966, 47806]
    },
    {
      "epc": "E28011910000000000000002",
      "peakRssi": -62,
      "antennaId": 2
    }
  ]
}
# 启动指定配置文件的虚拟读写器
dotnet run --project src/LlrpVirtualDevice.Cli -- run --config ./my-virtual-reader.json

5. 配置校验与能力查询

在启动前校验 JSON 格式合法性，或查看内置能力档案的详细参数： 

# 校验配置文件是否合规
dotnet run --project src/LlrpVirtualDevice.Cli -- validate --config ./my-virtual-reader.json

# 查询支持的能力 Profile
dotnet run --project src/LlrpVirtualDevice.Cli -- caps

6. 与第三方客户端生态互操作

虚拟读写器提供标准 LLRP TCP 连接和盘点联调路径；高级厂商行为与真实设备互操作仍应按具体客户端和 profile 单独验证：

  • Impinj ItemTest：R420-shaped profile 已有连接与盘点联调记录；其它 ItemTest 功能仍需单独验证。
  • 其它 LLRP 客户端：可用于连接、版本协商和标准盘点路径测试，具体兼容性取决于客户端实现。
  • LLRPCSharp 本项目 LlrpSdk 与 LlrpCli：可直接连接本 CLI 服务进行软件联调。
