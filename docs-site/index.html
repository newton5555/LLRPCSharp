推荐调用顺序

01ConnectAsync()连接并完成能力初始化
02GetDefaultSettingsAsync()取得设备相关的默认基线
03ApplySettingsAsync(settings)部署配置，保持停止
04StartInventoryAsync()启动已部署资源并读取报告
05StopAsync()停止托管盘点，保留配置

控制层原则

托管 API 是默认路径。专家资源 API 用来临时查看和操作 ROSpec / AccessSpec；Raw 用来承接 SDK 尚未封装的报文。低层写操作可能让设备观测变旧，但 SDK 保留托管意图，后续可以恢复自己的资源。
