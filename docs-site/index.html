📡 PART 1 · 上位机开发与现场运维

Reader SDK & 现场运维工具 (`llrp`)

面向业务的工业级托管客户端，用于连接真实物理读写器（如 Impinj Speedway, Zebra FX 系列）或虚拟读写器，执行协议版本自适应、不可变配置管理、独占流式标签消费以及 C1G2 读/写/锁/灭/块擦除。

📡
NuGet: LlrpSdk

Reader SDK (`LlrpSdk`)

高层托管客户端，已内置底层 LlrpNet.Core 协议内核（无需单独安装）。

  • LlrpReaderBuilder 链式配置与协议版本自动探查
  • ReaderSettings.Edit() 不可变配置变更意图
  • InventorySession 流式异步标签消费 (IAsyncEnumerable)
  • 读/写/锁/灭/块擦除标准 C1G2 Tag Access
  • 可选厂商扩展包：LlrpSdk.Extensions.Impinj / Zebra
查阅 Reader SDK API 参考 (含示例) → 查看底层 LlrpNet 协议 API →
⚡
独立 CLI 工具

LlrpCli (`llrp`) 现场运维与抓包分析

提供现场运维交互 Shell、单次自动化 JSON 调度以及离线 Wireshark .pcapng 抓包深度解析：

# 1. 启动现场交互式运维终端
llrp

# 2. 单次盘点 10 秒并输出 JSON 标签数组
llrp inventory 192.168.1.100 --duration 10 --yes

# 3. 离线深度解析 Wireshark 抓包文件
llrp decode ./capture.pcapng --output summary

💻 Reader SDK 三行代码极速连接与盘点 (C#)
using LlrpSdk;

// 1. 构建并连接读写器（自动完成 LLRP 1.0.1 / 1.1 协议版本探查与能力获取）
await using var reader = LlrpReader.CreateBuilder("192.168.1.100").Build();
await reader.ConnectAsync();

// 2. 获取基于硬件能力推荐的默认设置并下发 (安全接管，保留第三方配置)
var defaults = await reader.GetDefaultSettingsAsync();
await reader.ApplySettingsAsync(defaults.Settings);

// 3. 启动盘点并异步流式消费标签
await using var session = await reader.StartInventoryAsync();
await foreach (TagReport tag in session.ReadReportsAsync())
{
    Console.WriteLine($"[天线 {tag.AntennaId}] EPC: {tag.EpcHex}, RSSI: {tag.PeakRssi} dBm");
}
🖥️ PART 2 · 虚拟设备仿真与自动化测试

Device SDK & 虚拟读写器服务 (`llrp-device`)

确定性软件虚拟读写器与标准 LLRP TCP 服务端引擎。专为脱机 CI/CD 单元测试（xUnit）与无硬件环境下的第三方上位机（如 Impinj ItemTest 2.10.0）联调而设计。

🖥️
NuGet: LlrpDevice.Virtual.Hosting

Device SDK (`LlrpDevice.*`)

支持在测试中绑定临时端口 (Port=0) 启动完全合规的内存虚拟读写器。

  • VirtualLlrpDeviceHost 一键拉起内存读写器宿主
  • LlrpDeviceServer 高并发 TCP 报文路由与 LLRP 状态机
  • 内置 llrp1.0.1_standard 与 Impinj R420 仿真能力档案
  • 可插拔 ILlrpDevice 接口支持对接自定义真实硬件驱动
查阅 Device SDK API 参考 (含测试示例) →

独立 CLI 工具

LlrpVirtualDevice.Cli (`llrp-device`) 虚拟服务

无需编写代码，一条指令启动独立 LLRP TCP 读写器服务器（默认端口 5084）：

# 1. 前台启动并加载高密度仓库场景预设 (warehouse)
llrp-device run --port 5084 --preset warehouse

# 2. 交互式带帧级日志追踪运行传送带场景 (conveyor)
llrp-device live --port 5084 --preset conveyor

# 3. 校验自定义 JSON 仿真场景配置文件
llrp-device validate ./my-scenario.json

💻 xUnit 自动化测试中使用 VirtualLlrpDeviceHost 示例 (C#)
using System.Net;
using LlrpDevice.Virtual.Hosting;
using LlrpSdk;
using Xunit;

public class VirtualReaderTests
{
    [Fact]
    public async Task Reader_Should_Read_Simulated_Tags_On_Ephemeral_Port()
    {
        // 1. 在临时空闲端口 (Port = 0) 启动内存虚拟读写器
        var hostOptions = new VirtualDeviceHostOptions
        {
            ListenAddress = IPAddress.Loopback,
            Port = 0,
            Inventory = new VirtualInventoryOptions
            {
                Tags = [new VirtualInventoryTag
                {
                    ElectronicProductCode = Convert.FromHexString("E28011910000000000000001"),
                    AntennaId = 1,
                    PeakRssi = -55
                }]
            }
        };

        await using var host = await VirtualLlrpDeviceHost.CreateAndStartAsync(hostOptions);

        // 2. 客户端连接该临时端口并执行盘点
        await using var reader = LlrpReader.CreateBuilder("127.0.0.1")
            .WithPort(host.BoundPort)
            .Build();

        await reader.ConnectAsync();
        Assert.NotNull(reader.Capabilities);
    }
}

NuGet 获取方式与真实发布包清单

LLRPCSharp 遵循模块化设计，核心协议内核（LlrpNet.Core）已直接封装进各功能包中，您仅需根据开发场景引入对应的 NuGet 包：

NuGet 官方包版本职责定位快速安装指令
LlrpSdk ↗ v2.0.3 上位机客户端核心库（包含高层门面、不可变配置与内置协议内核） dotnet add package LlrpSdk
LlrpDevice.Virtual.Hosting ↗ v2.0.3 自动化测试虚拟宿主（xUnit / 临时端口 Port=0 嵌入仿真） dotnet add package LlrpDevice.Virtual.Hosting

dotnet add package LlrpSdk --version 2.0.3

dotnet add package LlrpDevice.Virtual.Hosting --version 2.0.3

dotnet add package LlrpSdk.Extensions.Zebra --version 2.0.3
