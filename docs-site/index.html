上位机开发

Reader SDK (LlrpSdk)

面向业务应用的高层托管客户端，参考 Octane 理念设计。版本自适应、强类型配置、响应式报告流消费与 C1G2 内存全操作。

  • LlrpReaderBuilder 链式连接与自动版本探查
  • ReaderSettings 声明式配置与天线功率索引映射
  • InventorySession 流式异步消费与 AttachedData
  • 读/写/锁/灭/块擦除标准 C1G2 Tag Access
  • Impinj 主路径、Zebra 实验性扩展与 Seuic profile

🖥️
设备端与测试

Device SDK (LlrpDevice.*)

通用的 LLRP 服务端与确定性软件虚拟读写器。专为无硬件自动化测试、CI/CD 流水线以及自定义读写器设备固件桥接而设计。

  • LlrpDeviceServer 高并发 TCP 报文路由与状态机
  • VirtualLlrpDevice 天线、可控 RSSI 抖动与确定性场景
  • VirtualLlrpDeviceHost 可嵌入 xUnit / 集成测试
  • 内置标准 1.0.1 与 Impinj Speedway R420 软件 profile
  • ILlrpDevice 接口支持对接自定义真实射频硬件
查看 Device SDK 指南 →

现场运维 & 诊断

Reader CLI (LlrpCli / llrp)

现场工程师的瑞士军刀与 Agent 自动化工具。提供实时交互 Shell、单次 JSON 命令输出以及强大的离线协议分析能力。

  • 交互式 Live Shell：实时滚屏盘点、天线配置与状态同步
  • 自动化命令：单条命令执行盘点并输出结构化 JSON
  • 离线 decode：直接解析 Wireshark .pcapng 抓包
  • inspect / validate / encode 协议报文构造与校验
  • 多版本编解码支持（1.0.1 / 1.1 / 2.0 基线 + 厂商扩展）

仿真环境运行

Device CLI (LlrpVirtualDevice.Cli)

独立运行的虚拟读写器服务终端。无需编写业务代码即可启动软件 LLRP 服务，供兼容客户端进行连接与盘点联调。

  • 一键启动读写器服务：llrp-device run --port 5084
  • 预设场景库：传送带 (Conveyor)、仓库 (Warehouse)、门禁 (Portal)
  • 交互式 Live 模拟：运行时动态添加/移除标签与故障注入
  • 仿真配置文件 JSON 校验与能力 Profile 查询
  • 可用于 ItemTest / 第三方 LLRP 客户端的连接与盘点联调；具体厂商功能仍以实际验证为准

WORKFLOW

标准 SDK 推荐调用顺序

01 ConnectAsync() 建立连接并完成协议版本探查与能力初始化
02 GetDefaultSettingsAsync() 获取适配当前设备物理能力的推荐默认配置
03 ApplySettingsAsync(settings) 部署业务配置并完成资源下发（保持停止状态）
04 StartInventoryAsync() 启动已部署的 ROSpec 并消费异步标签报告流
05 StopAsync() 停止托管盘点并保留当前配置定义
