READER SDK / MINIMAL EXAMPLE

复制这段代码，开始读取标签

这是从连接到盘点的最短路径。需要调整天线、RF Mode 或 Tag Access 时，再进入完整指南和 API Reference。

C# / .NET 10
Program.csLlrpSdk
using LlrpSdk;

await using var reader = LlrpReader
    .CreateBuilder("192.168.1.100")
    .WithPort(5084)
    .Build();

await reader.ConnectAsync();
await reader.ApplySettingsAsync(
    (await reader.GetDefaultSettingsAsync()).Settings);

await using var inventory = await reader.StartInventoryAsync();
await foreach (var tag in inventory.ReadReportsAsync())
{
    Console.WriteLine(tag.EpcHex);
}
01
连接

ConnectAsync 完成 TCP 会话与协议协商。

02
配置

默认设置来自当前设备能力，可按需编辑后应用。

03
盘点

ReadReportsAsync 返回统一的 TagReport。
