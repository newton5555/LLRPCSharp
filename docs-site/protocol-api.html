Framing 帧拆装核心类型

LlrpFrameDecoder Class
命名空间: LlrpNet.Core.Framing

基于 ReadOnlySpan<byte> 的高性能二进制帧流解析器。支持无堆分配地提取 10 字节 LLRP 标准帧头与负载切片。

方法签名

方法签名说明
bool TryDecodeFrame(ReadOnlySpan<byte> source, out LlrpFrame frame, out int consumedBytes) 尝试从缓冲区切片中解析出一个完整的 LLRP 帧。返回 false 表示数据不完整（半包），需要等待更多网络字节。

实战代码示例 (C# Code Sample)

using LlrpNet.Core.Framing;

var decoder = new LlrpFrameDecoder();

// 模拟接收到的 16 字节 GET_READER_CAPABILITIES 消息二进制报文
ReadOnlySpan<byte> rawBytes = stackalloc byte[] 
{ 
    0x04, 0x01,                   // Type=1 (GET_READER_CAPABILITIES), Version=1
    0x00, 0x00, 0x00, 0x10,       // Length=16 bytes
    0x00, 0x00, 0x00, 0x01,       // MessageID=1
    0x00, 0x00, 0x00, 0x00        // RequestedData=All
};

if (decoder.TryDecodeFrame(rawBytes, out LlrpFrame frame, out int consumedBytes))
{
    Console.WriteLine($"解析成功: Type={frame.TypeNumber}, Length={frame.Length}, MsgID={frame.MessageId}");
    Console.WriteLine($"负载长度: {frame.Payload.Length} 字节, 已消费字节: {consumedBytes}");
}
LlrpFrameEncoder Class
命名空间: LlrpNet.Core.Framing

将消息类型、版本与负载组装为标准的 10 字节 LLRP 报头格式。

Transport 会话与网络传输

LlrpSession Class
命名空间: LlrpNet.Core.Session

全双工异步消息会话管理通道。负责将网络底层字节流解包为消息帧，并将通知（如 RO_ACCESS_REPORT）推入事件管道，将响应消息匹配到等待中的 TransactAsync 任务。

实战代码示例 (C# Code Sample)

using LlrpNet.Core.Session;
using LlrpNet.Core.Transport;

// 1. 建立 TCP 传输
await using var transport = new LlrpTcpTransport("192.168.1.100", 5084);
await transport.ConnectAsync(CancellationToken.None);

// 2. 创建会话管理管道
await using var session = new LlrpSession(transport);
session.Start();

// 3. 监听异步主动上报消息 (RO_ACCESS_REPORT)
session.MessageReceived += (sender, msg) =>
{
    Console.WriteLine($"收到主动上报报文: Type={msg.TypeNumber}, MsgID={msg.MessageID}");
};

Codec 编解码器注册表

LlrpCodecRegistry Class
命名空间: LlrpNet.Core.Codec

中央编解码器注册表。管理标准 1.0.1 / 1.1 / 2.0 及 Impinj / Zebra 厂商扩展的序列化器与反序列化器。

实战代码示例 (C# Code Sample)

using LlrpNet.Core.Codec;
using LlrpNet.Protocol.V1_0_1;
using V101Messages = LlrpNet.Protocol.Messages.V1_0_1;

// 1. 注册标准 1.0.1 模块
var registry = new LlrpCodecRegistry();
registry.RegisterModule(new Llrp101StandardModule());

// 2. 强类型消息序列化为二进制
var getCaps = new V101Messages.GET_READER_CAPABILITIES
{
    MessageID = 100,
    RequestedData = LlrpNet.Protocol.Enumerations.V1_0_1.GetReaderCapabilitiesRequestedData.All
};
byte[] wireBytes = registry.EncodeMessage(getCaps);

// 3. 二进制报文反序列化为强类型实例
ILLRPMessage decoded = registry.DecodeMessage(wireBytes);
if (decoded is V101Messages.GET_READER_CAPABILITIES typedMsg)
{
    Console.WriteLine($"反序列化成功: RequestedData={typedMsg.RequestedData}");
}

多版本命名空间规则

显式多版本命名空间隔离 Convention

LLRPCSharp 要求所有涉及协议类型的代码使用显式别名导入，杜绝使用隐式“默认版本”： 

using V101Messages = LlrpNet.Protocol.Messages.V1_0_1;
using V101Parameters = LlrpNet.Protocol.Parameters.V1_0_1;
using V11Messages = LlrpNet.Protocol.Messages.V1_1;
using V11Parameters = LlrpNet.Protocol.Parameters.V1_1;

// 1.0.1 协议类型
V101Parameters.ROSpec roSpec101 = new V101Parameters.ROSpec();

// 1.1 协议类型 (概念相同，版本独立隔离)
V11Parameters.ROSpec roSpec11 = new V11Parameters.ROSpec();
