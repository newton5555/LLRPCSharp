ESCAPE HATCHES

专家资源 API 桥接运行已有 ROSpec Raw Protocol 通道 三条安全规则

03 / EXPERT & RAW ESCAPE HATCHES

深入协议底层，完成后无缝返回托管层

专家和 Raw API 是托管 API 的正交扩展通道：允许你绕过高级抽象查看设备现状、试验非标资源、发送自定义厂商报文，然后回到高层的会话与标签报告模型。

专家资源 API (IRoSpecService & IAccessSpecService)

连接就绪 (Ready) 后，可直接通过 reader.RoSpecs 和 reader.AccessSpecs 操作读写器资源。查询操作不会改变状态；修改操作会让设备资源观测变为 Stale，但 不会清除 SDK 持有的 DesiredSettings。 

// 1. 查询读写器当前所有已存在的 ROSpec
var roSpecs = await reader.RoSpecs.GetAllAsync(cancellationToken);

// 2. 添加并管理自定义 ROSpec (例如 ID = 600)
await reader.RoSpecs.AddAsync(customRoSpecParameter, cancellationToken);
await reader.RoSpecs.EnableAsync(600, cancellationToken);
await reader.RoSpecs.StartAsync(600, cancellationToken);
await reader.RoSpecs.StopAsync(600, cancellationToken);
await reader.RoSpecs.DisableAsync(600, cancellationToken);
await reader.RoSpecs.DeleteAsync(600, cancellationToken);

// 3. 删除全部资源需显式指定 ReplaceAll 策略
await reader.RoSpecs.DeleteAllAsync(ResourceTakeoverPolicy.ReplaceAll, cancellationToken);
提示： 专家资源 API 在连接 Ready 后随时可用，不需要像旧版 SDK 那样显式进入或退出“手动模式”。

桥接已有 ROSpec 到高层标签流

当你通过专家 API 或外部系统在设备上创建了特殊的 ROSpec，但依然希望使用 SDK 强大的异步标签流 (InventorySession)、背压控制和生命周期管理时，使用 StartExistingRoSpecAsync： 

// 1. 通过专家 API 或外部系统部署自定义 ROSpec 600
await reader.RoSpecs.AddAsync(customRoSpec, ct);

// 2. 桥接为 SDK 的 InventorySession 会话
await using InventorySession session = await reader.StartExistingRoSpecAsync(600, ct);

// 3. 实时接收标签报告
await foreach (TagReport tag in session.ReadReportsAsync(ct))
{
    Console.WriteLine($"[EPC] {tag.EpcHex} | 天线: {tag.AntennaId}");
}
关键区别： StartExistingRoSpecAsync 不编译、不删除、不覆盖指定的 ROSpec；会话结束 (Stop/Dispose) 时也会保留该 ROSpec，不会从设备上删除。

Raw Protocol 通道 (IReaderProtocolAccess)

reader.Protocol 提供了向读写器发送任意已编码/未封装消息和原始二进制帧的能力。SDK 会自动串行化 Raw 操作与托管资源操作，避免并发控制冲突。 

using V101Messages = LlrpNet.Protocol.Messages.V1_0_1;

// 1. 发送强类型消息事务
var response = await reader.Protocol.TransactAsync<V101Messages.CUSTOM_MESSAGE_RESPONSE>(
    new V101Messages.CUSTOM_MESSAGE(reader.Protocol.NextMessageId())
    {
        // 组装厂商私有参数
    },
    cancellationToken: ct);

// 2. 发送原始二进制帧 (零拷贝)
ReadOnlyMemory<byte> requestFrame = File.ReadAllBytes("custom-frame.bin");
ReadOnlyMemory<byte> responseFrame = await reader.Protocol.TransactRawAsync(
    requestFrame,
    responseMatcher: frame => frame.Span[1] == 0x04, // 自定义匹配器
    cancellationToken: ct);
READ-ONLY

GET 查询消息

如 GET_ROSPECS，仅读取状态，不会使托管观测失效。

MUTATING

写 / 删 / 启停消息

如 DELETE_ROSPEC，标记 Observed=Stale，但保留 DesiredSettings。

三条安全规则

01 想运行外部或手工创建的 ROSpec，使用 StartExistingRoSpecAsync(id)。
02 想让 SDK 根据 Desired 重新收敛并恢复盘点，使用无参 StartInventoryAsync()。
03 只有在应用明确独占整台读写器所有资源时，才使用 ReplaceAll。
