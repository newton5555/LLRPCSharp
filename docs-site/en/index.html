LLRPCSHARP / DOCUMENTATION

An industrial LLRP foundation
for modern .NET

LLRPCSharp is a protocol and application foundation for RFID reader software. It combines the Reader SDK, a deterministic software Device SDK, operational CLI tools and generated, versioned LLRP protocol models.

Reader SDK

High-level reader client

Describe reader intent with typed settings, negotiate an explicit protocol version, stream tag reports and perform standard C1G2 access operations.

  • LLRP 1.0.1 and 1.1 adapter baselines
  • Generated 2.0 protocol layer and adapter baseline
  • Inventory, AttachedData and Tag Access APIs
  • Impinj extension package and explicit version types
Open the Reader SDK guide →
🧪
Device SDK

Virtual reader and server

Run a deterministic software LLRP TCP endpoint in tests or host a custom ILlrpDevice implementation. This is not a physical RF waveform simulator.

  • Ephemeral-port xUnit and integration tests
  • Repeatable tags, RSSI jitter and memory access
  • Standard server lifecycle and resource routing
  • Hosting and low-level APIs

Operations

Reader CLI

Connect to readers from a live shell, automate inventory and settings workflows, perform Tag Access and inspect offline protocol traffic.

  • Live status, capabilities and inventory
  • Explicit settings validation and takeover policies
  • Raw frame and PCAPNG diagnostics
  • JSON output for scripts and agents
Open the Reader CLI guide →
⚙️
Device CLI

Virtual Device CLI

Launch and manage deterministic virtual LLRP readers from the command line with protocol/profile presets or a schema 1 JSON configuration.

  • Standard 1.0.1, 1.1 and 2.0 presets
  • Impinj R420-shaped software profile
  • Live lifecycle and event log controls
  • Config validation and capability inspection

What is usable today

AreaCurrent position

LLRP 2.0Generated protocol layer and SDK adapter baseline; real-device interoperability is not yet verified.
Vendor extensionsImpinj is the primary extension path. Zebra is experimental and requires byte-level/device validation. Seuic is represented by profile defaults.
Virtual deviceDeterministic TCP software for protocol, lifecycle and business-flow tests; it does not model RF physics.
