LLRPCSharp is a high-performance, zero-native-dependency LLRP infrastructure for modern .NET. The project is structured into two core tracks: Reader SDK (Client API & `llrp` maintenance CLI) and Device SDK (Virtual Reader API & `llrp-device` simulation CLI), providing complete coverage for physical reader integration and offline automated testing.

📡 PART 1 · CLIENT APPLICATION & MAINTENANCE

Reader SDK & Field Maintenance CLI (`llrp`)

Business-oriented managed client for physical readers (Impinj Speedway, Zebra FX series) and virtual readers. Features protocol version discovery, immutable configuration, exclusive async tag streams, and C1G2 tag access.

📡
NuGet: LlrpSdk

Reader SDK (`LlrpSdk`)

High-level managed client with embedded LlrpNet.Core wire engine (no separate install required).

  • LlrpReaderBuilder fluent configuration and endpoint setup
  • ReaderSettings.Edit() immutable configuration intent
  • InventorySession exclusive async stream (IAsyncEnumerable)
  • Standard C1G2 Tag Access (Read, Write, Lock, Kill, Block Erase)
  • Optional vendor extensions: LlrpSdk.Extensions.Impinj / Zebra

LlrpCli (`llrp`) Field Maintenance & Analysis

Provides interactive Live Shell, single-shot JSON automation, and offline Wireshark .pcapng decoding:

# 2. Automated single-shot inventory for 10s with JSON output

# 3. Offline decode Wireshark .pcapng capture
llrp decode ./capture.pcapng --output summary

💻 Reader SDK Quick Connect & Inventory in 3 Steps (C#)
using LlrpSdk;

// 1. Build and connect to reader (auto discovers LLRP 1.0.1 / 1.1 protocol)
await using var reader = LlrpReader.CreateBuilder("192.168.1.100").Build();
await reader.ConnectAsync();

// 2. Obtain capability-aware default settings and deploy (PreserveForeign safe takeover)
var defaults = await reader.GetDefaultSettingsAsync();
await reader.ApplySettingsAsync(defaults.Settings);

// 3. Start inventory and stream tag reports asynchronously
await using var session = await reader.StartInventoryAsync();
await foreach (TagReport tag in session.ReadReportsAsync())
{
    Console.WriteLine($"[Antenna {tag.AntennaId}] EPC: {tag.EpcHex}, RSSI: {tag.PeakRssi} dBm");
}
🖥️ PART 2 · VIRTUAL DEVICE SIMULATION & AUTOMATED TESTING

Device SDK & Virtual Reader Server (`llrp-device`)

Deterministic software virtual reader and standard LLRP TCP server engine. Designed for offline CI/CD unit testing (xUnit) and hardware-free 3rd-party client testing (e.g. Impinj ItemTest 2.10.0).

🖥️
NuGet: LlrpDevice.Virtual.Hosting

Device SDK (`LlrpDevice.*`)

Embed fully compliant in-memory virtual readers on ephemeral ports (Port=0) in test suites.

  • VirtualLlrpDeviceHost in-memory test host lifecycle
  • LlrpDeviceServer TCP message routing and state machines
  • Built-in llrp1.0.1_standard & Impinj R420 capability profiles
  • Pluggable ILlrpDevice interface for custom hardware drivers

💻 VirtualLlrpDeviceHost in xUnit Automated Test Sample (C#)
using System.Net;
using LlrpDevice.Virtual.Hosting;
using LlrpSdk;
using Xunit;

public class VirtualReaderTests
{
    [Fact]
    public async Task Reader_Should_Read_Simulated_Tags_On_Ephemeral_Port()
    {
        // 1. Start in-memory virtual reader on ephemeral port (Port = 0)
        var hostOptions = new VirtualDeviceHostOptions
        {
            ListenAddress = IPAddress.Loopback,
            Port = 0,
            Inventory = new VirtualInventoryOptions
            {
                Tags = [new VirtualInventoryTag
                {
                    ElectronicProductCode = Convert.FromHexString("E28011910000000000000001"),
                    AntennaId = 1,
                    PeakRssi = -55
                }]
            }
        };

        await using var host = await VirtualLlrpDeviceHost.CreateAndStartAsync(hostOptions);

        // 2. Client connects to the ephemeral port and reads tags
        await using var reader = LlrpReader.CreateBuilder("127.0.0.1")
            .WithPort(host.BoundPort)
            .Build();

        await reader.ConnectAsync();
        Assert.NotNull(reader.Capabilities);
    }
}
