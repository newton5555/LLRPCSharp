05 / EXPERT PROTOCOL ACCESS

Drop to protocol detail and return to managed APIs

The expert surface is for applications that need ROSpec/AccessSpec ownership or protocol messages outside the high-level intent model. It keeps raw work visible and serializes it with managed operations.

Expert resource APIs

IRoSpecService and IAccessSpecService expose explicit resource creation, update, start, stop, query and deletion operations. Use them when a reader workflow cannot be represented by ReaderSettings.

OperationBoundary
AddRoSpecAsyncCreate a ROSpec under the caller's explicit ownership.
EnableRoSpecAsync / StartRoSpecAsyncMove an existing resource through the reader lifecycle.
GetRoSpecsAsync / DeleteRoSpecAsyncObserve or remove resources deliberately.

Bridge an existing ROSpec

When an external system already owns a ROSpec, StartExistingRoSpecAsync(id) can connect its reports to the managed stream without replacing the definition.

Ownership: do not use managed settings to overwrite a resource that another application owns. Select PreserveForeign or bridge the existing resource explicitly.

Raw protocol channel

reader.Protocol can transact typed messages or raw byte frames. Use explicit version aliases for generated types and let the SDK serialize raw and managed operations.

using V101Messages = LlrpNet.Protocol.Messages.V1_0_1;

var response = await reader.Protocol.TransactAsync<V101Messages.CUSTOM_MESSAGE_RESPONSE>(
    new V101Messages.CUSTOM_MESSAGE(reader.Protocol.NextMessageId()),
    cancellationToken: ct);

ReadOnlyMemory<byte> requestFrame = File.ReadAllBytes("custom-frame.bin");
ReadOnlyMemory<byte> responseFrame = await reader.Protocol.TransactRawAsync(
    requestFrame,
    responseMatcher: frame => frame.Span[1] == 0x04,
    cancellationToken: ct);

Three safety rules

  1. Keep protocol version names explicit; do not introduce a default-version alias.
  2. Assume a mutating raw operation makes the managed observation stale and synchronize before reasoning about the device.
  3. Use an exclusive takeover policy only when the reader is truly owned by this process.
