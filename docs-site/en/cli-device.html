LlrpVirtualDevice.Cli (`llrp-device`) Virtual Reader Server Manual

LlrpVirtualDevice.Cli (command alias llrp-device) is a standalone virtual LLRP reader server. Without writing code, you can start a standard 5084 LLRP TCP server, load presets or custom tag scenarios, and serve any compliant LLRP client.

1. Overview & Launch Options

# Start interactive host management shell
dotnet run --project src/LlrpVirtualDevice.Cli

# Or run foreground service with warehouse preset on port 5084
dotnet run --project src/LlrpVirtualDevice.Cli -- run --port 5084 --preset warehouse

2. Core Commands & Options

Command SyntaxDescription & Example
llrp-device run [options] Launch foreground server: llrp-device run --port 5084 --preset warehouse
llrp-device live [options] Start server with interactive RX/TX logging: llrp-device live --port 5084 --preset conveyor
llrp-device presets List all built-in scenario presets.
llrp-device validate <config.json> Validate configuration file schema and tag data.

3. Interactive Host Management Shell

server create --llrp 1.0.1 --port 5084  # Create host instance
server start                            # Bind port and begin accepting clients
server status                           # Display state & connected clients
logs on / logs off                      # Toggle live RX/TX LLRP frame tracing

4. Scenario Presets & Custom Configuration

conveyor

Simulates tags passing dynamic antenna interrogation zones at speed.

warehouse

Multi-antenna high tag density inventory for throughput testing.

portal

Dual-sided portal gate for rapid group tag transit verification.

5. 3rd-Party Interop (Impinj ItemTest)

llrp-device is fully compliant with LLRP standards. Connect commercial software (e.g. Impinj ItemTest 2.10.0) to 127.0.0.1:5084 for live verification.
