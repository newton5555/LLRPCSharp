LLRPCSHARP / COMMAND-LINE INTERFACE MANUAL

LLRPCSharp CLI Command-Line Tools User Manual

LLRPCSharp provides two distinct CLI tools: LlrpCli (`llrp`) for real reader maintenance, live scripting, and Wireshark capture analysis, and LlrpVirtualDevice.Cli (`llrp-device`) for standalone virtual reader simulation.

PART 01 / READER CLIENT OPERATIONS & ANALYSIS

1. LlrpCli (`llrp`) Reader Client & Analysis Manual

LlrpCli provides an interactive Live Shell for maintenance, single-shot JSON commands for script automation, and an offline engine to decode Wireshark .pcapng captures.

1.1 Launch Options & Standalone Binary

# Run interactive shell directly from repository
dotnet run --project src/LlrpCli

# Or publish as standalone single-file binary (no .NET runtime required)
dotnet publish src/LlrpCli -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
./src/LlrpCli/bin/Release/net10.0/win-x64/publish/llrp.exe

1.2 Interactive Live Shell Command Reference

Command SyntaxDescription & Options
connect <ip> [--port 5084] Connect to reader, negotiate LLRP version, and query capabilities.
status [--full] Display connection state, negotiated version, and staged settings.
caps [--raw] [--json] Query normalized hardware capabilities and RF power/mode tables.
settings apply --defaults --yes Deploy reader-recommended settings baseline.
settings apply <file.json> --yes Deploy settings from JSON file (PreserveForeign).
settings apply <file.json> --yes --replace-all Delete all foreign resources and deploy exclusively.
settings show [--json] [--raw] Read and inspect live configuration from reader.
inventory start [--monitor live|frames] Start inventory and stream tag reports in terminal.
inventory stop Stop managed inventory.
tag read / write / lock / kill Perform C1G2 tag memory operations.
sync Resynchronize observed device state from reader.

1.3 Single-Shot Automation Commands (JSON Output)

# Connect, inventory for 10 seconds and output standard JSON array
llrp inventory 192.168.1.100 --duration 10 --yes

1.4 Wireshark Capture Analysis (.pcapng)

# Decode Wireshark capture to summary overview
llrp decode ./capture.pcapng --output summary

# Decode detailed parameter tree with vendor extension
llrp decode ./capture.pcapng --extension impinj --output detail

PART 02 / STANDALONE VIRTUAL READER SERVER

2. LlrpVirtualDevice.Cli (`llrp-device`) Virtual Reader Server Manual

llrp-device is a standalone virtual LLRP reader server. Start a standard 5084 LLRP TCP server with pre-configured scenarios without writing code.

2.1 Core Run Modes

Command SyntaxDescription & Example
llrp-device run [options] Launch foreground server: llrp-device run --port 5084 --preset warehouse
llrp-device live [options] Start server with interactive RX/TX logging: llrp-device live --port 5084 --preset conveyor
llrp-device presets List all built-in scenario presets.
llrp-device validate <config.json> Validate scenario configuration file schema and tag data.

2.2 Interactive Host Shell

server create --llrp 1.0.1 --port 5084  # Create instance
server start                            # Bind port and accept clients
server status                           # View running state & clients
logs on / logs off                      # Toggle live RX/TX frame tracing
