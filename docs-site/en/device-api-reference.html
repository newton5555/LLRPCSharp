LLRPCSHARP / DEVICE SDK PUBLIC API REFERENCE

Device SDK API reference

LlrpDevice.* contains the device-side server, hosting facade and deterministic virtual-reader types used for protocol and integration tests. It is not an RF waveform simulator.

Typical code

var options = new VirtualDeviceHostOptions
{
    ListenAddress = IPAddress.Loopback,
    Port = 0,
    Inventory = new VirtualInventoryOptions
    {
        Tags = [new VirtualInventoryTag
        {
            ElectronicProductCode = Convert.FromHexString("E28011910000000000000001"),
            AntennaId = 1,
            PeakRssi = -55
        }]
    }
};
await using IVirtualLlrpDeviceHost host = VirtualLlrpDeviceHost.Create(options);
await host.StartAsync();

Hosting lifecycle

VirtualLlrpDeviceHost Class

Composes a virtual device and LLRP server for an embeddable TCP endpoint.

static Create(VirtualDeviceHostOptions)Build a host instance.
StartAsyncStart listening and expose BoundPort.
StopAsyncStop the listener and release resources.

VirtualDeviceHostOptions Record

Profile, endpoint, protocol version, inventory and simulation options for a host.

ProfileIdCapability/profile selection.
ListenAddress / PortBind address and port; 0 requests an ephemeral port.
ProtocolVersionExplicit software protocol selection.
Inventory / SimulationTag data and deterministic behavior options.

Server engine

LlrpDeviceServer Class

Generic device-side LLRP TCP engine for a supplied ILlrpDevice.

LlrpDeviceServerOptions Record

Listener address, port, idle timeout and frame-assembly timeout.

Virtual engine

VirtualDeviceOptions Record

Low-level profile, capability, configuration, tag and RF-simulation setup.

VirtualInventoryTag Record

Hosting-level tag data: EPC bytes, optional TID/User memory, antenna and RSSI.
