LlrpCli (`llrp`) Reader Client & Analysis Manual

LlrpCli (command alias llrp) is an industrial-grade CLI tool built on LlrpSdk. It provides an interactive Live Shell for maintenance, single-shot JSON commands for script automation, and an offline engine to decode Wireshark .pcapng captures.

1. Overview & Launch Options

# Run interactive shell directly from repository
dotnet run --project src/LlrpCli

# Or publish as standalone single-file binary (no .NET runtime required)
dotnet publish src/LlrpCli -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
./src/LlrpCli/bin/Release/net10.0/win-x64/publish/llrp.exe

2. Interactive Live Shell Command Reference

2.1 Connection & Status Commands

connect <ip> [--port 5084]Connect to reader and discover LLRP version
status [--full]Display connection state and staged configuration
caps [--raw] [--json]Query normalized hardware capabilities and RF tables

2.2 Settings Commands

settings apply --defaults --yesDeploy reader-recommended settings baseline
settings apply <file.json> --yesDeploy settings from JSON file (PreserveForeign)
settings apply <file.json> --yes --replace-allDelete all foreign resources and deploy exclusively
settings show [--json] [--raw]Read and inspect live configuration from reader
settings editInteractive menu to adjust antennas, RF modes & sessions

2.3 Tag Inventory Commands

inventory start [--monitor live|frames]Start inventory and stream tag reports in terminal
inventory status [--refresh]Display current inventory execution status
inventory stopStop managed inventory

2.4 C1G2 Tag Operations

tag read --epc <hex> --bank user --ptr 0 --count 2Read memory bank of matched tag
tag write --epc <hex> --bank user --ptr 0 --data 12345678Write data to tag memory
tag lock --epc <hex> --user-lock SecuredWriteLock memory bank with access password
tag kill --epc <hex> --password <hex>Permanently decommission tag

3. Single-Shot Automation Commands (Agent/CI)

# Connect, inventory for 10 seconds and output standard JSON
llrp inventory 192.168.1.100 --duration 10 --yes

4. Wireshark Capture Analysis (.pcapng)

# Decode Wireshark capture to summary overview
llrp decode ./capture.pcapng --output summary

# Decode detailed parameter tree with vendor extension
llrp decode ./capture.pcapng --extension impinj --output detail

5. Offline Codec & Diagnostic Tools

# Inspect raw hex frame into human-readable parameter tree
llrp inspect 04030000001000000001000000000000

# Encode JSON object into raw LLRP binary frame
llrp encode ./message.json
