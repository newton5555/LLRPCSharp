LLRPCSHARP / READER SDK PUBLIC API REFERENCE

Reader SDK API reference

LlrpSdk exposes typed settings intent, asynchronous inventory, standard C1G2 access, expert ROSpec control and raw protocol transactions for modern .NET. The 1.0.1 and 1.1 adapters are usable baselines; 2.0 is an adapter baseline pending real-device interoperability.

Overview

Target
.NET 10 / async streams
Protocol
LLRP 1.0.1 and 1.1 usable · 2.0 adapter baseline
Extensions
Impinj primary · Zebra experimental · Seuic profile defaults
State
Desired intent separated from observed device facts

Typical code

await using var reader = LlrpReader.CreateBuilder("192.168.1.100")
    .WithPort(5084)
    .Build();
await reader.ConnectAsync();
ReaderSettingsDefaults defaults = await reader.GetDefaultSettingsAsync();
await reader.ApplySettingsAsync(defaults.Settings);

Core facade and lifecycle

LlrpReader Class

Owns the reader connection, protocol negotiation, managed resources and report delivery.

ConnectAsyncOpen the transport and negotiate the configured policy.
StartInventoryAsyncDeploy or start a managed inventory session.
ApplySettingsAsyncValidate and deploy reader intent without starting inventory.

LlrpReaderBuilder Class

Builds a reader with endpoint, timeout, explicit protocol policy and extension registrations.

Settings and inventory

ReaderSettings Record

Immutable reader intent containing configuration and inventory settings.

InventorySettings Record

Version-neutral inventory intent for antennas, RF mode, session, population, filters and attached data.

InventorySession Class

Async lifecycle for a managed inventory run and its IAsyncEnumerable<TagReport> stream.

TagReport Record

Unified EPC, antenna, RSSI, timestamp and access-result projection.

C1G2 Tag Access

TagAccessRequest Record

Base request family for read, write, lock, kill and block-erase operations.

Expert and raw protocol

IRoSpecService Interface

Explicit ROSpec resource lifecycle operations.

IReaderProtocolAccess Interface

Typed transactions and raw byte-frame access.

Vendor extensions

Impinj Extension

Primary extension path for Serialized TID, RF phase, peak RSSI and search mode options.

Zebra Experimental

Wire package and SDK extension baseline; validate against the target model and firmware.

Seuic Profile

Known model/profile defaults, not a complete vendor acceptance claim.

Exceptions

LlrpConnectionExceptionTransport or connection lifecycle failure.
LlrpUnexpectedResponseExceptionResponse type does not match the pending transaction.
SettingsValidationExceptionIntent failed validation against the current reader capabilities.
