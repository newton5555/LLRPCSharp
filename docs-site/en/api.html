01 / API GUIDE & OVERVIEW

Drive LLRP with a modern .NET managed API

LlrpSdk is a version-aware high-level API inspired by the intent-oriented style of Impinj Octane. Applications describe reader intent; the SDK compiles it into the negotiated protocol's ROSpec and AccessSpec resources while keeping the protocol channel available. LLRP 1.0.1 and 1.1 are usable baselines. LLRP 2.0 has a generated layer and adapter baseline, but real-device interoperability still needs separate acceptance.

Getting started

Create a reader, connect, read capability-derived defaults, apply settings and consume an asynchronous inventory stream.

using LlrpSdk;

await using var reader = LlrpReader.CreateBuilder("192.168.1.100")
    .WithPort(5084)
    .WithConnectTimeout(TimeSpan.FromSeconds(5))
    .Build();

await reader.ConnectAsync();
ReaderSettingsDefaults defaults = await reader.GetDefaultSettingsAsync();
await reader.ApplySettingsAsync(defaults.Settings);

await using InventorySession session = await reader.StartInventoryAsync();
await foreach (TagReport tag in session.ReadReportsAsync())
{
    Console.WriteLine($"[antenna {tag.AntennaId}] EPC: {tag.EpcHex} | RSSI: {tag.PeakRssi} dBm");
}
Lifecycle: InventorySession is IAsyncDisposable. Leaving an await using scope stops the managed inventory and releases its report stream.

Capabilities and numeric indexes

LLRP represents RF modes and transmit power as numeric indexes. Interpret those indexes through reader.Capabilities instead of assuming that an index means the same thing on every reader.

ReaderCapabilities caps = reader.Capabilities!;
Console.WriteLine($"Antennas: {caps.MaxNumberOfAntennas}");

foreach (var mode in caps.RfModes)
    Console.WriteLine($"RF mode {mode.ModeIdentifier}: M={mode.MValue}, Tari={mode.MinTariValue}ns");

foreach (var power in caps.TxPowers)
    Console.WriteLine($"Power index {power.Index}: {power.TransmitPowerDbm:F2} dBm");

ReaderSettings

ReaderSettings is an immutable, typed intent model for antennas, RF mode, Gen2 session, population and keepalive behavior. Edit a known baseline and apply the result.

ReaderSettings defaultSettings = (await reader.GetDefaultSettingsAsync()).Settings;

ReaderSettings customSettings = defaultSettings.Edit(builder => builder
    .Configuration(defaultSettings.Configuration with
    {
        Keepalive = new KeepaliveConfiguration
        {
            TriggerType = KeepaliveTriggerType.Periodic,
            IntervalMs = 5000
        }
    })
    .Inventory(inv => inv
        .Antennas(1, 2)
        .Mode(modeIndex: 1000)
        .Session(2)
        .Population(64)
        .ReportEveryTag()));

await reader.ApplySettingsAsync(customSettings);

Managed inventory and report streams

CallBehaviorTypical use
StartInventoryAsync(settings)Deploy the supplied intent and start inventory.One-step inventory.
ApplySettingsAsync(settings)Deploy settings while leaving inventory stopped.Two-step orchestration.
StartInventoryAsync()Start the deployed or retained desired configuration.Explicit start or recovery.
StartExistingRoSpecAsync(id)Bridge an existing external ROSpec into the SDK report pipeline.Raw-resource integration.
Choose one report outlet: session.ReadReportsAsync(), reader.ReadTagReportsAsync() and reader.TagsReported are mutually exclusive for one inventory run.

AttachedData

Inventory can request TID or User memory alongside EPC reporting through InventorySettings.AttachedData. The exact memory layout and access result still depend on reader capability and tag behavior.

var inventory = new InventorySettings
{
    AntennaIds = [1, 2],
    AttachedData = new AttachedDataOptions
    {
        Enabled = true,
        MemoryBank = 2,
        WordPointer = 0,
        WordCount = 6,
        AccessPassword = "00000000"
    }
};

await using var session = await reader.StartInventoryAsync(inventory);
await foreach (TagReport tag in session.ReadReportsAsync())
    Console.WriteLine($"EPC: {tag.EpcHex}");

C1G2 Tag Access

The SDK supports standard Gen2 read, write, lock, kill and block-erase operations. Selectors keep the target tag explicit.

var selection = new TagSelection
{
    MemoryBank = TagMemoryBank.ElectronicProductCode,
    BitPointer = 32,
    BitLength = 96,
    Mask = Convert.FromHexString("FFFFFFFFFFFFFFFFFFFFFFFF"),
    Data = Convert.FromHexString("E28011910000000000000001")
};

TagAccessResult result = await reader.WriteTagMemoryAsync(new WriteTagRequest
{
    Selection = selection,
    MemoryBank = TagMemoryBank.User,
    WordPointer = 0,
    WriteData = [0x1234, 0x5678],
    AccessPassword = "00000000"
});

ResourceTakeoverPolicy

The policy controls what happens to resources already present on a reader when managed settings are deployed.

Recommended default

PreserveForeign

Replace only SDK-owned reserved resources (ROSpec 14150 and AccessSpec 14151) and preserve resources owned by other clients.

Explicit exclusive mode

ReplaceAll

Delete all ROSpec and AccessSpec resources before deployment. Use only when the reader is exclusively owned by this application.

Vendor extensions

Impinj is the primary extension path. Use explicit protocol namespaces when selecting vendor enumeration values.

using LlrpNet.Protocol.Impinj.Enumerations.V1_0_1;
using LlrpSdk.Extensions.Impinj;

var reader = LlrpReader.CreateBuilder("192.168.1.100")
    .UseImpinj()
    .Build();

var inventory = new InventorySettings().Edit(b => b
    .Impinj(imp => imp
        .IncludeSerializedTid()
        .IncludeRfPhaseAngle()
        .IncludePeakRssi()
        .SearchMode(ImpinjInventorySearchType.Dual_Target)));

await reader.ConnectAsync();
await using var session = await reader.StartInventoryAsync(inventory);
Interop boundary: Impinj features need a compatible reader/profile. Zebra is experimental and requires true-device validation; Seuic currently provides profile/default mappings rather than a complete vendor acceptance path.
