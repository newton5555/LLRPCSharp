02 / DEVICE & VIRTUAL SERVER SDK

LLRP server and deterministic virtual reader core

LlrpDevice.* provides a standards-oriented device-side TCP server and a deterministic software reader that can run on an ephemeral port in automated tests. It exercises protocol, lifecycle and business-flow behavior; it does not simulate physical RF waveforms.

Modules and responsibilities

LlrpDevice.Abstractions

Device contracts, capabilities, status and inventory/access execution interfaces.

LlrpDevice.Server

TCP listener, LLRP routing, resource registry, keepalive and report assembly.

LlrpDevice.Virtual

Repeatable tag visibility, RSSI variation and C1G2 memory behavior.

LlrpDevice.Virtual.Hosting

VirtualLlrpDeviceHost composes the server and virtual device with async lifecycle methods.

Quick test with xUnit

Start the host on port 0, let the operating system choose a free port, then connect the Reader SDK to it.

using System.Net;
using LlrpDevice.Virtual.Hosting;
using LlrpSdk;
using Xunit;

[Fact]
public async Task Reader_reads_simulated_tags()
{
    var options = new VirtualDeviceHostOptions
    {
        ListenAddress = IPAddress.Loopback,
        Port = 0,
        Inventory = new VirtualInventoryOptions
        {
            Tags =
            [
                new VirtualInventoryTag
                {
                    ElectronicProductCode = Convert.FromHexString("E28011910000000000000001"),
                    AntennaId = 1,
                    PeakRssi = -55
                }
            ]
        }
    };

    await using IVirtualLlrpDeviceHost host = VirtualLlrpDeviceHost.Create(options);
    await host.StartAsync();

    await using var reader = LlrpReader.CreateBuilder(IPAddress.Loopback.ToString())
        .WithPort(host.BoundPort)
        .Build();
    await reader.ConnectAsync();

    ReaderSettingsDefaults defaults = await reader.GetDefaultSettingsAsync();
    await reader.ApplySettingsAsync(defaults.Settings);
    await using var session = await reader.StartInventoryAsync();

    await foreach (TagReport tag in session.ReadReportsAsync())
    {
        Assert.Equal("E28011910000000000000001", tag.EpcHex);
        break;
    }
}
Lifecycle: VirtualLlrpDeviceHost implements async disposal and releases the TCP listener when the test exits.

LlrpDevice.Server

LlrpDeviceServer is independent of a particular RF implementation. It routes versioned messages, tracks ROSpec and AccessSpec resources, handles keepalive and emits reports according to the configured report specification.

var serverOptions = new LlrpDeviceServerOptions
{
    ListenAddress = IPAddress.Any,
    Port = 5084,
    IdleTimeout = TimeSpan.FromMinutes(5),
    FrameAssemblyTimeout = TimeSpan.FromSeconds(30)
};

await using var server = new LlrpDeviceServer(new MyHardwareDevice(), serverOptions);
await server.StartAsync();

LlrpDevice.Virtual

The virtual engine provides repeatable software behavior: tag-to-antenna filtering, seeded RSSI jitter, configurable report timing and persistent C1G2 memory operations.

VISIBILITY

Antenna filtering

Tags are reported according to their configured antenna and the active device profile.

VARIANCE

RSSI jitter

Use a seed and integer dB jitter to reproduce edge cases consistently.

MEMORY

C1G2 storage

EPC, TID, User and password-related operations can be exercised in software.

using LlrpDevice.Virtual;

var deviceOptions = new VirtualDeviceOptions
{
    RfSimulation = new VirtualRfSimulationOptions
    {
        Scenario = VirtualRfScenario.Noisy,
        RandomSeed = 2026,
        RssiJitterDb = 2
    },
    Tags =
    [
        new VirtualTagDefinition
        {
            ElectronicProductCode = Convert.FromHexString("E280119100000000000000A1"),
            Tid = Convert.FromHexString("E28011052000600123456789"),
            UserMemory = [0xCAFE, 0xBABE],
            AntennaId = 1,
            PeakRssi = -48,
            AccessPassword = 0x00000000
        }
    ]
};

Built-in capability profiles

Profiles define capabilities such as antenna ports, power tables, RF modes and protocol defaults. Profile behavior is software behavior and should not be read as evidence of a particular physical reader.

Profile IDPurpose
llrp1.0.1_standardStandard LLRP 1.0.1 software baseline.
impinj.r420.llrp-1.0.1Impinj R420-shaped profile with extension paths.
llrp1.1_standardLLRP 1.1 software baseline.

Bridge a custom hardware backend

Implement ILlrpDevice when a proprietary RF or serial backend needs a standard LLRP TCP facade. The server remains responsible for protocol handling; the backend supplies capabilities and execution results.

public sealed class MyRfDevice : ILlrpDevice
{
    public ReaderCapabilities Capabilities => ...;
    public ReaderStatus Status => ...;

    public Task<IInventoryExecution> StartInventoryAsync(
        InventoryExecutionParameters parameters,
        CancellationToken cancellationToken) => ...;

    public Task<TagAccessOperationResult> ExecuteTagAccessAsync(
        TagAccessRequest request,
        CancellationToken cancellationToken) => ...;
}
