06 / STATE AND RESOURCE MODEL

Device reality and managed intent

Readers can be changed by several clients or by manual protocol commands. LLRPCSharp therefore separates the application's desired configuration from the device's observed facts.

Two state dimensions

DESIRED STATE

What the application wants

Set by ApplySettingsAsync or StartInventoryAsync(settings). Raw operations do not erase the retained intent.

reader.DesiredSettings
OBSERVED STATE

What the device currently has

Updated by connection queries, events and synchronization. It may be Unknown, Stale or Synchronized.

reader.ObservedState

Typical transition

01

Managed inventory runs

Desired settings are retained and managed ROSpec 14150 is synchronized.

02

A raw or external change occurs

A DELETE_ROSPEC or another external mutation changes the device; observed state becomes stale while desired settings remain.

03

Facts are refreshed

SynchronizeStateAsync() queries the device and confirms what exists. It does not automatically redeploy the missing resource.

04

Managed state converges again

A parameterless StartInventoryAsync() can compile and deploy the retained desired settings.

What SynchronizeStateAsync does

SynchronizeStateAsync() is an observation operation, not a destructive repair command.

It does:
  • Query ROSpec and AccessSpec snapshots.
  • Identify managed and foreign resources.
  • Update ObservedState from the returned facts.
It does not:
  • Rewrite or delete resources automatically.
  • Prevent another client from changing the reader after the query.
  • Decode private vendor parameters without the matching extension.

Recovery and rebuilding

If the managed resource was removed or the reader reset, redeploy the retained intent explicitly.

// After a raw operation deletes the managed ROSpec:
 // reader.ObservedState is stale, but reader.DesiredSettings remains.
await using InventorySession session = await reader.StartInventoryAsync();
Foreign resources: use StartExistingRoSpecAsync(roSpecId) to bridge a proprietary ROSpec instead of overwriting it with managed settings.
