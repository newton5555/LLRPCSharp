NuGet 包

v2.0.3 发布工作流会打包以下四个公开包：

Package用途安装
LlrpSdk ↗托管 Reader 客户端、设置、盘点和标准 Tag Access。dotnet add package LlrpSdk --version 2.0.3
LlrpSdk.Extensions.Impinj ↗Impinj 协议与 Reader SDK 扩展。dotnet add package LlrpSdk.Extensions.Impinj --version 2.0.3
LlrpSdk.Extensions.Zebra ↗Zebra 协议与 Reader SDK 扩展基线。dotnet add package LlrpSdk.Extensions.Zebra --version 2.0.3
LlrpDevice.Virtual.Hosting ↗在测试或应用进程内启动单台虚拟 LLRP 设备。dotnet add package LlrpDevice.Virtual.Hosting --version 2.0.3

当前 Release workflow 发布的是 Reader CLI 压缩包；Virtual Device CLI 是解决方案中的独立测试工具，可从源码运行或按项目需求自行发布。

v2.0.3 版本说明

  • 托管 DesiredState 与 Reader ObservedState 分离，Raw/专家操作不会静默覆盖应用意图。
  • 新增显式资源接管策略：默认 PreserveForeign，需要独占时选择 ReplaceAll。
  • 保持 LLRP 1.0.1、1.1 和 2.0 SDK 基线；2.0 的真实设备互操作仍需单独验收。
  • 发布 LlrpSdk、Impinj 扩展、Zebra 扩展和 LlrpDevice.Virtual.Hosting v2.0.3。
