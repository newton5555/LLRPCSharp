LlrpVirtualDevice.Cli (`llrp-device`) 虚拟读写器服务手册

LlrpVirtualDevice.Cli（命令别名 llrp-device）是独立运行的 LLRP 虚拟读写器服务端程序。无需编写代码，一条命令即可启动一台标准的 LLRP TCP 读写器服务器（默认端口 5084），供任意第三方 LLRP 客户端或业务系统进行仿真联调。

1. 工具概述与使用场景

# 方式 1：通过仓库源码直接启动交互控制台
dotnet run --project src/LlrpVirtualDevice.Cli

# 方式 2：启动前台服务并加载 warehouse 仓库高密度场景预设
dotnet run --project src/LlrpVirtualDevice.Cli -- run --port 5084 --preset warehouse

2. 核心运行命令速查

命令格式功能说明与示例
llrp-device run [options] 前台静默服务模式启动读写器（适合容器部署或后台运行）。
llrp-device run --port 5084 --preset warehouse
llrp-device live [options] 启动服务并进入带实时 RX/TX 帧级日志追踪的交互式终端。
llrp-device live --port 5084 --preset conveyor
llrp-device presets 列出系统内置的所有场景预设名称与说明。
llrp-device validate <config.json> 校验自定义仿真场景配置文件的 JSON Schema 与标签数据完整性。

3. 交互式 Host 管理控制台

直接运行 llrp-device 不带子命令即可进入宿主管理控制台：

# 控制台常用管理命令：
server create --llrp 1.0.1 --port 5084  # 创建读写器实例（尚未绑定端口）
server start                            # 绑定网络端口并开始接受客户端连接
server status                           # 查看运行状态与已连接客户端 IP
server restart                          # 重启 TCP 监听器并断开客户端
server stop                             # 停止服务
caps                                    # 列出当前读写器注册的能力 Profile
logs on / logs off                      # 开启或关闭实时 RX/TX LLRP 报文追踪日志

4. 场景预设与自定义 JSON 配置规范

conveyor (传送带场景)

模拟标签以特定速度穿越天线感应区域，产生动态的进入与离开事件。

warehouse (仓库高密度盘点)

模拟 4 根天线覆盖下的上百张高密度标签群，用于压力与吞吐量测试。

portal (通道门禁场景)

模拟双侧门禁天线感应，适用于批量进出库校验。

自定义 JSON 配置文件示例：

{
  "profile": "llrp1.0.1_standard",
  "port": 5084,
  "inventory": {
    "tags": [
      {
        "epc": "E28011910000000000000001",
        "antennaId": 1,
        "rssi": -55,
        "tid": "E280110520007001",
        "user": "12345678"
      },
      {
        "epc": "E28011910000000000000002",
        "antennaId": 2,
        "rssi": -62
      }
    ]
  }
}

5. 第三方客户端联调 (如 Impinj ItemTest)

llrp-device 完全遵循 LLRP 1.0.1 / 1.1 国际规范。启动后，可以使用商业上位机软件（如 Impinj ItemTest 2.10.0）直接输入 127.0.0.1:5084 建立连接并执行盘点测试。
