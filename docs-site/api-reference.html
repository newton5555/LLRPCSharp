LLRPCSharp / PUBLIC API REFERENCE

LLRPCSharp SDK API 完整技术参考手册

面向 .NET 10 的现代化 LLRP SDK 公开类型、属性、方法签名、参数与返回值索引。提供强类型的版本无关高层门面、C1G2 内存访问、专家资源编排以及零拷贝协议通道。

API 架构概览

LlrpSdk 采用三层递进的控制模型设计，满足从简易业务盘点到深度协议调试的全部场景：

目标框架
.NET 10 (C# 14 / Async Streams)
支持协议基线
LLRP 1.0.1 · LLRP 1.1 · LLRP 2.0
厂商扩展模块
Impinj (Octane) · Zebra (Motorola) · Seuic
资源管理模型
DesiredState 意图 与 ObservedState 事实解耦
核心设计原则：应用层代码建议从 LlrpReader.CreateBuilder(host) 进入。高层托管 API 自动编译 ROSpec/AccessSpec 并保持版本中立；当需要使用厂商私有参数或未封装指令时，可通过 reader.Protocol 和 reader.RoSpecs 无缝下沉，且不会破坏 SDK 内部期望状态。

典型代码示例

01. 连接读写器并开启异步标签盘点流 
using LlrpSdk;

// 1. 创建并构建读写器客户端
await using var reader = LlrpReader.CreateBuilder("192.168.1.100")
    .WithPort(5084)
    .WithConnectTimeout(TimeSpan.FromSeconds(5))
    .Build();

// 2. 建立连接并完成协议版本与硬件能力协商
await reader.ConnectAsync();

// 3. 获取基于该设备能力推荐的默认配置并下发
ReaderSettingsDefaults defaults = await reader.GetDefaultSettingsAsync();
await reader.ApplySettingsAsync(defaults.Settings);

// 4. 启动托管盘点会话并异步消费标签报告
await using var session = await reader.StartInventoryAsync();
await foreach (TagReport tag in session.ReadReportsAsync())
{
    Console.WriteLine($"[天线 {tag.AntennaId}] EPC: {tag.EpcHex} | RSSI: {tag.PeakRssi} dBm | 计数: {tag.SeenCount}");
}
02. 执行标准 C1G2 标签内存读取 (Tag Access) 
// 构建按 EPC 前缀匹配的标签选择器
var selection = new TagSelection
{
    MemoryBank = TagMemoryBank.ElectronicProductCode,
    BitPointer = 32, // 跳过 CRC (16-bit) 与 PC (16-bit)
    BitLength = 96,
    Mask = Convert.FromHexString("FFFFFFFFFFFFFFFFFFFFFFFF"),
    Data = Convert.FromHexString("E28011910000000000000001")
};

// 读取指定标签的 TID 存储区 (前 4 字 = 64 位)
TagAccessResult result = await reader.ReadTagMemoryAsync(new ReadTagRequest
{
    Selection = selection,
    MemoryBank = TagMemoryBank.Tid,
    WordPointer = 0,
    WordCount = 4,
    AccessPassword = "00000000"
});

if (result.Operation.Success)
{
    Console.WriteLine($"TID 读取成功: {string.Join(" ", result.Operation.ReadData.Select(w => w.ToString("X4")))}");
}

核心门面与生命周期 (Core Facade)

namespace LlrpSdk

LlrpReader

Class
public sealed class LlrpReader : IAsyncDisposable

代表与单个 RFID 读写器的完整会话连接。负责拥有底层 Transport 传输通道、LLRP 会话、编解码器注册表、协议版本适配器、主动消息分发泵以及高层业务生命周期。

常量与字段 (Constants)

名称类型值说明
ManagedInventoryRoSpecId uint 14150 SDK 托管盘点专用的保留 ROSpec ID。
ManagedInventoryAttachedDataAccessSpecId uint 14151 SDK 托管盘点附加读取 (AttachedData) 专用的保留 AccessSpec ID。

核心属性 (Properties)

属性类型说明
Options LlrpReaderOptions 构建此读写器时传入的不可变配置选项。
IsConnected · ConnectionState bool · ReaderConnectionState 当前网络与 LLRP 会话连接状态 (Disconnected / Connecting / Ready / Faulted)。
OperationState · ResourceMode · ObservedState Enums 运行中业务状态、资源占用模式 (ManagedExclusive / AttachedExisting) 与设备观测鲜度 (Synchronized / Stale)。
Identity · Capabilities · NegotiatedVersion Metadata 连接建立后协商出的硬件身份 (Vendor/Model/Firmware)、归一化能力表与协议版本。
DesiredSettings · CurrentInventorySettings Settings SDK 内部持久保留的期望配置意图，与当前正在运行的盘点配置。
RoSpecs · AccessSpecs · Protocol · Extensions Services 专家级 ROSpec 服务、AccessSpec 服务、低级协议直接通道与厂商扩展集合。

ReaderSettings

Record
public sealed record ReaderSettings

高层配置意图的根对象，包含读写器硬件参数 (Configuration)、可选盘点意图 (Inventory) 以及厂商私有扩展字段 (Extensions)。

属性类型说明

namespace LlrpSdk

InventorySettings

Record
public sealed record InventorySettings

定义单次托管盘点操作的版本中立意图模型。SDK 会在下发前自动将其编译为当前协商协议版本 (1.0.1 / 1.1 / 2.0) 对应的 ROSpec 与 AISpec 报文。

属性类型默认值说明
AntennaIds IReadOnlyList<ushort> [0] (全部天线) 参与盘点的天线列表。[0] 为标准全选简写，下发时自动展开为具体天线。
Session byte 0 Gen2 Singulation Session (取值 0, 1, 2, 3)。
TagPopulationEstimate ushort 32 预计辐射区域内的标签数量，用于读写器计算初始 Q 算法时隙。
ModeIndex · Tari ushort 0 (自动/默认) 指定 RF 模式表索引与 Tari 时间参数（根据 reader.Capabilities.RfModes 确定）。
ReportEveryNTags · Report ushort · InventoryReportSettings 1 · Default 每盘存到 N 张标签时触发一次上报，以及需要包含的字段开关。
Filters · AttachedData Collections / Options Empty · Disabled 标准 Gen2 Select 掩码过滤器与盘点期间附加读取内存配置 (AttachedData)。

C1G2 标签操作 (Tag Access)

namespace LlrpSdk

TagAccessRequest 体系

Record Hierarchy

用于在单次操作中按掩码匹配目标标签并执行标准 Gen2 内存操作。SDK 会临时建立专用的 AccessSpec 并在执行完毕后自动清理，无需手动编写复杂的协议参数。

请求类型核心参数说明
ReadTagRequest MemoryBank, WordPointer, WordCount 读取 Reserved / EPC / TID / User 存储区指定字长的数据。
WriteTagRequest MemoryBank, WordPointer, WriteData 向指定存储区写入 16-bit 字数组。
LockTagRequest TagLockMode (Kill/Access/EPC/TID/User) 修改各存储区与密码的权限 (Accessible / AlwaysAccessible / SecuredWrite / AlwaysNotWritable)。
KillTagRequest KillPassword (8 hex digits) 传入 32-bit 灭活密码永久销毁标签。
BlockEraseTagRequest MemoryBank, WordPointer, WordCount 按块擦除标签存储区。

IRoSpecService

Interface
public interface IRoSpecService

通过 reader.RoSpecs 直接向读写器下发 ROSpec 资源增删改查与启停指令。写操作会使 SDK 的 ObservedState 标记为 Stale，但保留 DesiredSettings。

方法说明
AddAsync(ILlrpParameter roSpec, CancellationToken) 下发并注册一个强类型或版本化的 ROSpec 参数。
EnableAsync(uint roSpecId) · DisableAsync(uint roSpecId) 启用或禁用指定 ID 的 ROSpec。
StartAsync(uint roSpecId) · StopAsync(uint roSpecId) 显式启动或停止已处于 Enabled 状态的 ROSpec。
DeleteAsync(uint roSpecId) · DeleteAllAsync(ResourceTakeoverPolicy.ReplaceAll) 删除单个 ROSpec 或在明确确认独占时清空设备所有 ROSpec。
GetAllAsync(CancellationToken) 查询并返回读写器当前所有已存在的 ROSpec 列表。
namespace LlrpSdk

IReaderProtocolAccess

Interface
public interface IReaderProtocolAccess : IReaderConnection

通过 reader.Protocol 暴露的强类型和原始帧交互接口，支持执行自定义厂商报文与未封装的标准 LLRP 指令。

方法签名说明

厂商扩展模块 (Vendor Extensions)

namespace LlrpSdk.Extensions.Impinj

Impinj 扩展模块 (Octane / Speedway / R420)

Extension

通过 builder.UseImpinj() 启用。自动注册 Impinj LLRP 1.0.1 编解码器并在连接匹配（IANA 25882）时激活以下能力：

扩展类型功能说明
ImpinjInventoryControlOptions 低占空比 (LowDutyCycle)、搜索模式 (DualTarget / SingleTargetWithSuppression)、标签估算算法、Gen2X 选项。
ImpinjInventoryReportOptions 开启 Serialized TID、RF 相位角 (RFPhaseAngle)、高精度 RSSI (0.01 dBm)、多普勒频移、GPS 坐标上报。
ImpinjReaderConfiguration GPI 防抖时间 (GPIDebounce)、链路监控 (LinkMonitor) 与扩展 GPO 脉冲配置。
namespace LlrpSdk.Extensions.Zebra

Zebra 扩展模块 (FX9600 / Motorola)

Extension

通过 builder.UseZebra() 启用（IANA 161）。支持查询与配置射频电源状态、自主模式、掉电参数保存，并在标签报告中投影 zebra.phase 与 zebra.brandIdCheckStatus。

namespace LlrpSdk.Extensions.Seuic

Seuic 扩展模块 (UF40)

Extension

通过 builder.UseSeuic() 启用（IANA 57690）。自动解析已知型号的硬件能力表并生成匹配的发射功率与接收灵敏度配置。

异常与错误诊断体系 (Exceptions)

异常类型基类触发原因与诊断信息
LlrpReaderOperationException Exception 读写器返回了非成功 (Non-Success) 的 LLRP 状态码。提供 StatusCode、ErrorDescription 与 RawStatus。
LlrpReaderConnectionException IOException 底层 TCP 传输断开或 LLRP 消息泵异常中止。
LlrpResourceCapacityException InvalidOperationException 即将部署的 ROSpec/AccessSpec 超出读写器在能力表中声明的物理容量上限。
LlrpUnexpectedResponseException Exception 读写器返回了与请求事务不匹配的非预期消息类型。
LlrpReaderBackpressureException Exception 上层应用消费标签报告速度过慢导致有界通道队列积压溢出。
SettingsValidationException InvalidOperationException 高层配置无法通过当前读写器硬件能力校验（包含完整的 Diagnostics 列表）。
