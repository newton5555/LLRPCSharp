LLRPCSHARP / READER SDK PUBLIC API REFERENCE

Reader SDK (.NET 读写器客户端) API 参考手册

LlrpSdk 提供面向 .NET 10 的现代化读写器客户端 API：强类型的不可变配置意图、流式异步盘点会话、C1G2 存储区全操作（读/写/锁/灭/块擦除）、专家级 ROSpec 资源编排与原始字节协议通道。

API 架构概览

目标框架
.NET 10 (C# 14 / Async Streams)
支持协议基线
LLRP 1.0.1 · LLRP 1.1 usable baselines · LLRP 2.0 adapter baseline
厂商扩展模块
Impinj primary · Zebra experimental · Seuic profile defaults
资源管理模型
DesiredState 意图 与 ObservedState 事实解耦

IReaderProtocolAccess Interface

典型代码示例

01. 连接读写器并消费标签流 (Inventory Stream) 
using LlrpSdk;

// 1. 创建并构建读写器
await using var reader = LlrpReader.CreateBuilder("192.168.1.100")
    .WithPort(5084)
    .WithConnectTimeout(TimeSpan.FromSeconds(5))
    .Build();

// 2. 建立连接（自动探查 LLRP 协议版本并查询硬件能力）
await reader.ConnectAsync();

// 3. 应用适配当前硬件能力的推荐默认配置
ReaderSettingsDefaults defaults = await reader.GetDefaultSettingsAsync();
await reader.ApplySettingsAsync(defaults.Settings);

// 4. 启动托管盘点会话并异步消费标签报告
await using var session = await reader.StartInventoryAsync();
await foreach (TagReport tag in session.ReadReportsAsync())
{
    Console.WriteLine($"[天线 {tag.AntennaId}] EPC: {tag.EpcHex} | RSSI: {tag.PeakRssi} dBm | 计数: {tag.SeenCount}");
}
02. 执行标准 C1G2 标签内存读取 (Tag Access) 
// 构建按 EPC 前缀匹配的标签选择器
var selection = new TagSelection
{
    MemoryBank = TagMemoryBank.ElectronicProductCode,
    BitPointer = 32, // 跳过 CRC (16-bit) 与 PC (16-bit)
    BitLength = 96,
    Mask = Convert.FromHexString("FFFFFFFFFFFFFFFFFFFFFFFF"),
    Data = Convert.FromHexString("E28011910000000000000001")
};

// 读取指定标签的 TID 存储区 (前 4 字 = 64 位)
TagAccessResult result = await reader.ReadTagMemoryAsync(new ReadTagRequest
{
    Selection = selection,
    MemoryBank = TagMemoryBank.Tid,
    WordPointer = 0,
    WordCount = 4,
    AccessPassword = "00000000"
});

if (result.Operation.Success)
{
    Console.WriteLine($"TID 读取成功: {string.Join(" ", result.Operation.ReadData.Select(w => w.ToString("X4")))}");
}

核心门面与生命周期 (Core Facade)

namespace LlrpSdk

LlrpReader

Class
public sealed class LlrpReader : IAsyncDisposable

代表与单个 RFID 读写器的完整会话连接。负责拥有底层 Transport 传输通道、LLRP 会话、编解码器注册表、协议版本适配器、主动消息分发泵以及高层业务生命周期。

常量与字段 (Constants)

名称类型值说明
ManagedInventoryRoSpecId uint 14150 SDK 托管盘点专用的保留 ROSpec ID。
ManagedInventoryAttachedDataAccessSpecId uint 14151 SDK 托管 AttachedData 专用的保留 AccessSpec ID。

核心属性 (Properties)

属性类型说明
ConnectionState ReaderConnectionState 当前网络与会话状态（Disconnected / Connecting / Ready / Faulted）。
OperationState ReaderOperationState 当前高层托管执行状态（Idle / Deploying / InventoryRunning / TagAccessRunning / Busy）。
ResourceMode ReaderResourceMode 当前资源控制权归属（Idle / ManagedExclusive / AttachedExisting / Manual）。
Capabilities ReaderCapabilities? 连接建立后自动查询并缓存的归一化硬件能力表（功率表、天线数、RF模式表）。未连接时为 null。
Protocol IReaderProtocolAccess 底层协议直接访问通道，用于发送强类型报文事务或 Raw 字节帧。
RoSpecs IRoSpecService 专家级 ROSpec 资源管理接口。

核心方法 (Methods)

方法签名说明
static LlrpReaderBuilder CreateBuilder(string host) 创建指向指定 IP 或主机名的读写器构建器。
Task ConnectAsync(CancellationToken cancellationToken = default) 建立 TCP 连接，探查 LLRP 协议版本，并完成硬件能力初始化。
Task<ReaderSettingsDefaults> GetDefaultSettingsAsync(CancellationToken) 基于当前连接设备的硬件能力表，计算并生成推荐的默认设置。
Task ApplySettingsAsync(ReaderSettings settings, ResourceTakeoverPolicy, ...) 将业务配置意图部署到读写器（下发 Reader 级配置并编译下发 ROSpec），下发后保持停止。
Task<InventorySession> StartInventoryAsync(InventorySettings?, ...) 启动托管盘点会话，返回包含流式标签报告消费接口的 InventorySession。
Task StopAsync(CancellationToken cancellationToken = default) 停止当前正在执行的托管盘点，保留已部署的配置。
Task<ReaderSettingsSnapshot> SynchronizeAsync(CancellationToken) 从物理读写器重新拉取实况（ROSpec、AccessSpec、配置），同步刷新本地观测状态。
namespace LlrpSdk

LlrpReaderBuilder

Class
public sealed class LlrpReaderBuilder

流式读写器构建器，用于在构建 LlrpReader 实例前配置端点、端口、协议协商策略与厂商扩展模块。

方法签名说明
LlrpReaderBuilder WithPort(int port) 指定读写器 TCP 端口（默认 5084）。
LlrpReaderBuilder WithConnectTimeout(TimeSpan timeout) 设置 TCP 连接建立与初始协议握手的超时时间（默认 5 秒）。
LlrpReaderBuilder WithProtocolVersionPolicy(LlrpProtocolVersionPolicy policy) 设置协议协商策略（Auto 自动协商 / Force101 / Force11 / Force20）。
LlrpReaderBuilder WithAutomaticReconnect(Action<LlrpAutomaticReconnectOptions>) 启用并配置网络断开后的自动重连退避策略。
LlrpReader Build() 创建并返回已配置的 LlrpReader 实例。

配置管理与盘点模型 (Settings & Inventory)

namespace LlrpSdk

ReaderSettings

Record
public sealed record ReaderSettings

不可变的高层配置意图容器。组合了 Reader 级全局硬件参数 (Configuration) 与托管盘点业务意图 (Inventory)。

属性类型说明
Configuration ReaderConfiguration Reader 级配置（事件抑制、心跳 Keepalive、天线默认 RF 模式/发射功率/接收灵敏度）。
Inventory InventorySettings? 默认盘点业务配置。为 null 时仅部署硬件级配置，不部署托管 ROSpec。
ReaderSettings Edit(Action<ReaderSettingsBuilder> configure) 基于当前配置副本进行流式链式修改，返回全新不可变实例。
namespace LlrpSdk

InventorySettings

Record
public sealed record InventorySettings

声明式的盘点意图模型。SDK 自动将其编译为当前协商协议版本的标准 ROSpec 与 AISpec 参数。

属性类型说明
AntennaIds IReadOnlyList<ushort> 启用的天线编号列表（例如 [1, 2]，空表示扫描全部天线）。
RfModeIndex ushort? 指定的 Gen2 RF Mode Index。对应 Capabilities.RfModes 中的调制/速率。
Session ushort? Gen2 Session (0, 1, 2, 3)。
TagPopulation ushort? 视野内预计标签数量（用于优化 Q 值算法，默认 32）。
AttachedData AttachedDataOptions? 盘存 EPC 时内嵌读取 TID 或 User 存储区的附加内存选项。
namespace LlrpSdk

InventorySession

Class
public sealed class InventorySession : IAsyncDisposable

代表单次运行中的盘点会话生命周期。支持通过 IAsyncEnumerable<TagReport> 进行高性能异步流式消费。

方法签名说明
IAsyncEnumerable<TagReport> ReadReportsAsync(CancellationToken) 获取异步标签报告迭代流。一个会话内该出口具有独占权。
Task StopAsync(CancellationToken cancellationToken = default) 显式停止当前盘点会话。
namespace LlrpSdk

TagReport

Record
public sealed record TagReport

统一归一化的标签观测结果。包含 EPC 十六进制字符串、天线 ID、信号强度 RSSI、观测时间戳与厂商扩展属性字典。

C1G2 标签操作 (Tag Access)

namespace LlrpSdk

TagAccessRequest (基类及派生请求)

Abstract

标准 C1G2 标签内存访问请求模型：

派生类型主要参数功能说明
ReadTagRequest Selection, MemoryBank, WordPointer, WordCount, AccessPassword 读取指定标签 EPC、TID、User 或 Reserved 存储区数据。
WriteTagRequest Selection, MemoryBank, WordPointer, WriteData, AccessPassword 向目标标签写入 16-bit 字数组数据。
LockTagRequest Selection, UserMemoryLockMode, EpcMemoryLockMode, AccessPassword 锁定或解锁目标标签的指定存储区或密码区。
KillTagRequest Selection, KillPassword 永久灭活/销毁目标标签。
BlockEraseTagRequest Selection, MemoryBank, WordPointer, WordCount 块擦除指定存储区的连续字。

厂商扩展模块 (Vendor Extensions)

namespace LlrpSdk.Extensions.Impinj

Impinj 扩展模块 (Octane / Speedway / R420)

Extension

通过 builder.UseImpinj() 启用。自动注册 Impinj LLRP 1.0.1 编解码器并在连接匹配（IANA 25882）时激活低占空比、搜寻模式、Serialized TID 与 RF 相位角上报。

namespace LlrpSdk.Extensions.Zebra

Zebra 扩展模块 (FX9600 / Motorola)

Extension

通过 builder.UseZebra() 启用（IANA 161）。这是实验性扩展路径；当前重点是标准连接/身份和已定义映射，FX9600 高级字段仍需按设备与固件完成字节级、真机验证。

namespace LlrpSdk.Extensions.Seuic

Seuic 扩展模块 (UF40)

Extension

通过 builder.UseSeuic() 启用（IANA 57690）。当前定位是已知型号的 profile/default 映射，用于生成匹配的能力与功率配置；不把它描述为独立的完整厂商协议验收。

异常与错误诊断体系 (Exceptions)

异常类型基类触发原因与诊断信息
LlrpReaderOperationException Exception 读写器返回了非成功 (Non-Success) 的 LLRP 状态码。提供 StatusCode、ErrorDescription 与 RawStatus。
LlrpReaderConnectionException IOException 底层 TCP 传输断开或 LLRP 消息泵异常中止。
LlrpResourceCapacityException InvalidOperationException 即将部署的 ROSpec/AccessSpec 超出读写器在能力表中声明的物理容量上限。
LlrpUnexpectedResponseException Exception 读写器返回了与请求事务不匹配的非预期消息类型。
LlrpReaderBackpressureException Exception 上层应用消费标签报告速度过慢导致有界通道队列积压溢出。
SettingsValidationException InvalidOperationException 高层配置无法通过当前读写器硬件能力校验（包含完整的 Diagnostics 列表）。
