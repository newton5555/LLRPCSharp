Reader SDK 核心门面

LlrpReader Class
命名空间: LlrpSdk · 实现: IAsyncDisposable

代表与单个物理或虚拟 LLRP 读写器的托管客户端会话。管理连接生命周期、协议版本自动探查、硬件能力查询、不可变配置下发与异步标签流分发。

核心方法与签名

方法签名说明与契约
Task ConnectAsync(CancellationToken cancellationToken = default) 建立底层 TCP 连接，探查并协商协议版本，初始化 Capabilities。若已连接则直接返回。
Task<ReaderSettingsDefaults> GetDefaultSettingsAsync(CancellationToken cancellationToken = default) 基于当前已连接设备的硬件能力表（天线数、功率表、RF 模式）生成推荐的默认配置基线。
Task ApplySettingsAsync(ReaderSettings settings, ResourceTakeoverPolicy takeoverPolicy = PreserveForeign, CancellationToken cancellationToken = default) 校验并将配置意图部署到读写器（部署后保持停止状态）。默认仅替换 SDK 自有资源。
Task<InventorySession> StartInventoryAsync(InventorySettings? settings = null, CancellationToken cancellationToken = default) 启动托管盘点并返回 InventorySession 会话实例。支持独占异步消费标签流。
Task StopAsync(CancellationToken cancellationToken = default) 停止当前正在运行的托管盘点，保留已下发的配置定义。

实战代码示例 (Code Example)

using LlrpSdk;

// 1. 构建并连接读写器
await using var reader = LlrpReader.CreateBuilder("192.168.1.100")
    .WithPort(5084)
    .WithConnectTimeout(TimeSpan.FromSeconds(5))
    .Build();

await reader.ConnectAsync();

// 2. 获取基于该设备真实能力生成的默认设置并下发
ReaderSettingsDefaults defaults = await reader.GetDefaultSettingsAsync();
await reader.ApplySettingsAsync(defaults.Settings);

// 3. 启动盘点并消费标签
await using InventorySession session = await reader.StartInventoryAsync();
await foreach (TagReport tag in session.ReadReportsAsync())
{
    Console.WriteLine($"天线 {tag.AntennaId} 读到 EPC: {tag.EpcHex}, RSSI: {tag.PeakRssi} dBm");
}
LlrpReaderBuilder Class
命名空间: LlrpSdk

提供链式流式 API 用于配置和创建 LlrpReader 实例。

实战代码示例 (Code Example)

using LlrpSdk;
using LlrpSdk.Extensions.Impinj;

var reader = LlrpReader.CreateBuilder("192.168.1.100")
    .WithPort(5084)                                // 指定端口
    .WithConnectTimeout(TimeSpan.FromSeconds(10))  // 连接超时
    .WithProtocolVersion(ProtocolVersionPolicy.Auto)// 自动协商 1.1 / 1.0.1
    .UseImpinj()                                   // 注册 Impinj 扩展
    .Build();
ReaderCapabilities Record
命名空间: LlrpSdk.Capabilities

存储连接成功后从读写器查询并归一化的硬件物理能力（天线数、功率表、RF 调制模式表等）。

实战代码示例 (Code Example)

ReaderCapabilities caps = reader.Capabilities!;
Console.WriteLine($"支持天线数量: {caps.MaxNumberOfAntennas}");

// 遍历发射功率索引表 (Index -> dBm 功率)
foreach (var pwr in caps.TxPowers)
{
    Console.WriteLine($"功率索引 {pwr.Index}: {pwr.TransmitPowerDbm:F2} dBm");
}

// 遍历 RF 模式表 (ModeIdentifier -> 调制参数)
foreach (var mode in caps.RfModes)
{
    Console.WriteLine($"RF Mode {mode.ModeIdentifier}: M={mode.MValue}, MinTari={mode.MinTariValue}ns");
}

配置管理与托管盘点流

ReaderSettings Record
命名空间: LlrpSdk.Configuration

不可变的读写器配置意图 Record，包含 Reader 级配置（心跳、事件过滤）与 Inventory 盘点意图。

实战代码示例 (Code Example)

ReaderSettings baseSettings = (await reader.GetDefaultSettingsAsync()).Settings;

// 使用不可变流式 Edit 构造新设置
ReaderSettings customSettings = baseSettings.Edit(b => b
    .Configuration(baseSettings.Configuration with
    {
        Keepalive = new KeepaliveConfiguration { TriggerType = KeepaliveTriggerType.Periodic, IntervalMs = 3000 }
    })
    .Inventory(inv => inv
        .Antennas(1, 2)
        .Mode(modeIndex: 1000)
        .Session(2)
        .Population(64)
        .ReportEveryTag()));

// 校验并下发到读写器
await reader.ApplySettingsAsync(customSettings);
InventorySession Class
命名空间: LlrpSdk · 实现: IAsyncDisposable

代表单次托管盘点会话。实现 IAsyncDisposable，在退出作用域时自动停止盘点并释放报告流通道。

实战代码示例 (Code Example)

using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(10));

await using InventorySession session = await reader.StartInventoryAsync();
try
{
    await foreach (TagReport tag in session.ReadReportsAsync(cts.Token))
    {
        Console.WriteLine($"收到标签: EPC={tag.EpcHex}, Antenna={tag.AntennaId}");
    }
}
catch (OperationCanceledException)
{
    Console.WriteLine("10 秒盘点时间到，自动结束。");
}
TagReport Record
命名空间: LlrpSdk

统一的标签报告投影，包含 EPC 十六进制字符串、天线号、RSSI、变长 PC 字、内联 Access 结果以及厂商扩展字段。

C1G2 标签操作 (Tag Access)

TagAccessRequest / TagSelection Records
命名空间: LlrpSdk.Access

标准 Gen2 内存访问请求族，支持按 EPC/TID 掩码过滤目标标签并执行读、写、锁、灭与块擦除。

实战代码示例 (Code Example)

// 1. 构造按 EPC 精确匹配的目标选择器
var selection = new TagSelection
{
    MemoryBank = TagMemoryBank.ElectronicProductCode,
    BitPointer = 32,
    BitLength = 96,
    Mask = Convert.FromHexString("FFFFFFFFFFFFFFFFFFFFFFFF"),
    Data = Convert.FromHexString("E28011910000000000000001")
};

// 2. 向 User 存储区 Word 0 写入 2 个字 (32位)
TagAccessResult writeResult = await reader.WriteTagMemoryAsync(new WriteTagRequest
{
    Selection = selection,
    MemoryBank = TagMemoryBank.User,
    WordPointer = 0,
    WriteData = [0x1234, 0x5678],
    AccessPassword = "00000000"
});

if (writeResult.Success)
{
    Console.WriteLine("写入标签 User 内存成功！");
}
TagAccessResult Record
命名空间: LlrpSdk.Access

表示单次 C1G2 访问操作的执行结果与读取数据。

专家资源管理与 Raw 协议通道

IRoSpecService / IAccessSpecService Interfaces
命名空间: LlrpSdk.Services

提供对读写器底层 ROSpec 和 AccessSpec 资源的直接增删改查控制与桥接运行。

实战代码示例 (Code Example)

// 1. 查询读写器当前所有已存在的 ROSpec
var roSpecs = await reader.RoSpecs.GetAllAsync();

// 2. 桥接运行外部创建的 ROSpec 100 并复用托管报告流
await using var session = await reader.StartExistingRoSpecAsync(roSpecId: 100);

{
    Console.WriteLine($"来自外部 ROSpec 100 的标签: {tag.EpcHex}");
}

Device SDK (虚拟设备与服务端)

VirtualLlrpDeviceHost Class
命名空间: LlrpDevice.Virtual.Hosting · 实现: IVirtualDeviceHost

组合 LlrpDeviceServer 与 VirtualLlrpDevice 的高层生命周期门面，专为在单元测试（xUnit）中启动临时 TCP 虚拟端点而设计。

实战代码示例 (Code Example)

using System.Net;
using LlrpDevice.Virtual.Hosting;
using LlrpSdk;
using Xunit;

public class VirtualDeviceTests
{
    [Fact]
    public async Task Reader_Should_Connect_And_Read_Simulated_Tags()
    {
        // 1. 在临时空闲端口 (Port = 0) 启动宿主
        var hostOptions = new VirtualDeviceHostOptions
        {
            ListenAddress = IPAddress.Loopback,
            Port = 0,
            Inventory = new VirtualInventoryOptions
            {
                Tags = [new VirtualInventoryTag
                {
                    ElectronicProductCode = Convert.FromHexString("E28011910000000000000001"),
                    AntennaId = 1,
                    PeakRssi = -55
                }]
            }
        };

        await using var host = await VirtualLlrpDeviceHost.CreateAndStartAsync(hostOptions);

        // 2. 客户端连接该临时端口
        await using var reader = LlrpReader.CreateBuilder("127.0.0.1")
            .WithPort(host.BoundPort)
            .Build();

        await reader.ConnectAsync();
        Assert.NotNull(reader.Capabilities);
    }
}

LlrpNet 协议层核心类型

LlrpFrameDecoder / LlrpFrameEncoder Classes
命名空间: LlrpNet.Core.Framing

基于 ReadOnlySpan<byte> 的高性能二进制 LLRP 帧拆装器。

实战代码示例 (Code Example)

using LlrpNet.Core.Framing;

var decoder = new LlrpFrameDecoder();
ReadOnlySpan<byte> rawBytes = stackalloc byte[] { 0x04, 0x03, 0x00, 0x00, 0x00, 0x10, 0x00, 0x00, 0x00, 0x01, 0x00, 0x00, 0x00, 0x00, 0x00, 0x00 };

if (decoder.TryDecodeFrame(rawBytes, out LlrpFrame frame, out int consumedBytes))
{
    Console.WriteLine($"解析到帧: TypeNumber={frame.TypeNumber}, Length={frame.Length}, MsgID={frame.MessageId}");
}
