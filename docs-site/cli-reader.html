LlrpCli (`llrp`) 读写器客户端与抓包分析用户手册

LlrpCli（命令别名 llrp）是基于 LlrpSdk 构建的工业级客户端 CLI 工具。提供用于现场维护的交互式 Live Shell、用于 CI/CD 自动化调度的单次 JSON 命令，以及免 Wireshark 的 .pcapng 抓包离线强类型解析引擎。

1. 工具概述与启动方式

# 方式 1：通过仓库源码直接运行
dotnet run --project src/LlrpCli

# 方式 2：发布为单一独立可执行文件 (零环境依赖，适合现场拷贝)
dotnet publish src/LlrpCli -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
./src/LlrpCli/bin/Release/net10.0/win-x64/publish/llrp.exe

2. 交互式 Live Shell 完整命令指南

直接运行 llrp 即可进入交互式现场运维终端：

2.1 连接与状态命令

connect <ip> [--port 5084]连接到读写器，自动完成协议版本探查与能力查询
status [--full]查看连接状态、协商协议版本以及已下发和期望的配置实况
caps [--raw] [--json]查询归一化硬件能力（天线数、发射功率表与 RF 模式表）

2.2 配置与参数管理

settings apply --defaults --yes基于当前读写器能力表，下发推荐的默认配置基线
settings apply <file.json> --yes从本地 JSON 配置文件部署设置（默认 PreserveForeign）
settings apply <file.json> --yes --replace-all删除读写器上所有既有资源，独占式部署新配置
settings show [--json] [--raw]拉取读写器实况配置并以表格或 JSON 格式展示
settings edit交互式菜单调整天线号、RF 模式与会话 (Session)

2.3 标签盘存命令

inventory start [--monitor live|frames]启动盘点并在终端实时滚屏显示接收到的标签 EPC、天线与 RSSI
inventory status [--refresh]查看当前盘点会话运行状态
inventory stop停止当前正在执行的盘点

2.4 C1G2 标签内存操作

tag read --epc <hex> --bank user --ptr 0 --count 2按 EPC 匹配标签并读取 User/TID 存储区
tag write --epc <hex> --bank user --ptr 0 --data 12345678向目标标签写入十六进制字数据
tag lock --epc <hex> --user-lock SecuredWrite锁定标签存储区（需提供 Access 密码）
tag kill --epc <hex> --password <hex>永久灭活目标标签

3. CI / Agent 自动化脚本命令 (JSON 输出)

# 自动连接、下发默认配置、盘点 10 秒并输出标准 JSON 标签数组
llrp inventory 192.168.1.100 --duration 10 --yes

# 校验本地 JSON 配置文件规范性
llrp settings validate ./reader-config.json

4. Wireshark 抓包离线深度解析 (`decode`)

# 输出会话报文时间线摘要
llrp decode ./capture.pcapng --output summary

# 挂载 Impinj 厂商扩展包，输出完整树状参数明细
llrp decode ./capture.pcapng --extension impinj --output detail

# 导出为结构化 JSON 文件
llrp decode ./capture.pcapng --output json > session.json

5. 协议 Codec 与报文帧分析 (`inspect` / `encode`)

# 将十六进制原始报文帧反编译为人类可读参数树
llrp inspect 04030000001000000001000000000000

# 将 JSON 消息定义编译为二进制线格式 Hex 字节流
llrp encode ./get_reader_capabilities.json
