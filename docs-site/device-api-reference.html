LLRPCSHARP / DEVICE SDK API REFERENCE

Device SDK (服务端与虚拟读写器) API 参考手册

LlrpDevice.* 系列包提供通用的 LLRP TCP 服务端引擎、虚拟读写器物理世界仿真核与嵌入式测试宿主。支持 3 行代码在单元测试与 CI 中启动内存读写器，或为真实射频硬件开发 LLRP 固件服务端。

典型使用代码示例

01. 在 xUnit 集成测试中启动虚拟读写器 
using LlrpDevice.Virtual;
using LlrpDevice.Virtual.Hosting;
using LlrpSdk;
using Xunit;

public class IntegrationTests
{
    [Fact]
    public async Task Reader_Should_Read_Simulated_Tags()
    {
        // 1. 创建虚拟读写器配置（Port=0 自动绑定空闲端口）
        var hostOptions = new VirtualDeviceHostOptions
        {
            Server = new LlrpDeviceServerOptions { Port = 0 },
            Device = new VirtualDeviceOptions
            {
                Tags = [ new VirtualTag { EpcHex = "E28011910000000000000001", AntennaId = 1, BaseRssi = -55.0 } ]
            }
        };

        // 2. 启动虚拟读写器
        await using IVirtualLlrpDeviceHost host = VirtualLlrpDeviceHost.Create(hostOptions);
        await host.StartAsync();

        // 3. 使用客户端连接测试
        await using var reader = LlrpReader.CreateBuilder("127.0.0.1").WithPort(host.BoundPort).Build();
        await reader.ConnectAsync();
        
        // 4. 盘点验证...
    }
}

宿主生命周期 (LlrpDevice.Virtual.Hosting)

namespace LlrpDevice.Virtual.Hosting

VirtualLlrpDeviceHost

Class
public sealed class VirtualLlrpDeviceHost : IVirtualLlrpDeviceHost

虚拟读写器宿主门面实现。组合了 LlrpDeviceServer 与 VirtualLlrpDevice，统一对外暴露生命周期与端口信息。

成员类型说明
static IVirtualLlrpDeviceHost Create(VirtualDeviceHostOptions options) Method 基于指定配置构建虚拟读写器宿主实例。
Task StartAsync(CancellationToken cancellationToken = default) Method 启动 TCP 监听服务端并初始化虚拟设备状态。
Task StopAsync(CancellationToken cancellationToken = default) Method 停止监听并断开所有活跃客户端连接。
int BoundPort { get; } Property 服务端实际绑定的本地 TCP 端口（当请求端口为 0 时返回系统分配的临时端口）。
VirtualLlrpDeviceHostState State { get; } Property 宿主当前生命周期状态（Created, Starting, Running, Stopping, Stopped）。
ILlrpDevice Device { get; } Property 获取宿主内部承载的虚拟设备实例。
namespace LlrpDevice.Virtual.Hosting

VirtualDeviceHostOptions

Record
public sealed record VirtualDeviceHostOptions
属性类型说明
Server LlrpDeviceServerOptions 网络与连接选项（端口、监听地址、客户端超时）。
Device VirtualDeviceOptions 虚拟硬件与射频行为选项（Profile、天线数、模拟标签列表、RSSI 抖动）。
InventoryDataSource IVirtualInventoryDataSource? 可选的独立动态盘点数据源发生器。

服务端协议引擎 (LlrpDevice.Server)

namespace LlrpDevice.Server

LlrpDeviceServer

Class
public sealed class LlrpDeviceServer : IAsyncDisposable

通用的独立 LLRP TCP 服务端引擎。内部维护客户端连接管道、帧拆装、版本协商与基于规范的 LlrpResourceRegistry 资源管理状态机。

namespace LlrpDevice.Server

LlrpDeviceServerOptions

Class
属性类型说明
ListenAddress IPAddress 监听的网络 IP 地址（默认 IPAddress.Any）。
Port int 监听端口（默认 5084，指定 0 自动分配临时端口）。
ClientConnectionTimeout TimeSpan 客户端握手与空闲连接超时时间。

虚拟仿真核 (LlrpDevice.Virtual)

namespace LlrpDevice.Virtual

VirtualDeviceOptions

Class
属性类型说明
Profile string 硬件能力预设标识符（默认 llrp1.0.1_standard）。
AntennaCount int 模拟的天线端口总数（默认 4）。
RssiJitterDb double 射频信号强度高斯随机抖动标准差（单位 dB）。

namespace LlrpDevice.Virtual

VirtualTag

Class
属性类型说明
EpcHex string EPC 十六进制编码（如 E28011910000000000000001）。
TidHex string? TID 存储区十六进制编码（如 E28011052000600123456789）。
UserMemoryHex string? User 存储区十六进制数据。
AntennaId ushort 当前所处的模拟天线端口编号。
BaseRssi double 基准接收信号强度（dBm，如 -55.0）。
AccessPassword string 8 字符十六进制访问密码（默认 00000000）。

设备端核心抽象 (LlrpDevice.Abstractions)

namespace LlrpDevice.Abstractions

ILlrpDevice

Interface
public interface ILlrpDevice

设备端通用行为接口，负责定义硬件能力、执行盘点通道与响应 C1G2 内存访问。

方法/属性说明
ReaderCapabilities Capabilities { get; } 设备硬件能力表（天线数、功率表、RF Mode 表）。
Task<IInventoryExecution> StartInventoryAsync(InventoryExecutionParameters, CancellationToken) 启动射频盘点通道并返回 IInventoryExecution。
Task<TagAccessOperationResult> ExecuteTagAccessAsync(TagAccessRequest, CancellationToken) 执行 C1G2 内存读写、加锁或灭活操作并返回结果。

内置能力 Profile 汇总

Profile 标识符天线数扩展与特性
llrp1.0.1_standard 4 标准 LLRP 1.0.1 协议基线，支持标准 Tari 与 Gen2 Session。
impinj.r420.llrp-1.0.1 4 Impinj Speedway Revolution R420 档案，支持 Impinj 厂商扩展与 RF 相位。
llrp1.1_standard 4 标准 LLRP 1.1 协议基线，支持版本协商与扩展字段。
