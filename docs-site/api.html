01 / API GUIDE & OVERVIEW

用现代 .NET 托管 API 驱动 LLRP

LlrpSdk 提供参考 Impinj Octane SDK 理念设计的版本无关高层 API。应用只需描述业务意图，SDK 自动将其编译为当前协商协议版本 (LLRP 1.0.1 / 1.1 / 2.0) 的标准 ROSpec 与 AccessSpec，同时保持底层零拷贝协议通道开放。

快速开始 (Getting Started)

最精简的调用链路：通过 Builder 创建连接，执行异步连接与能力初始化，下发推荐默认设置，然后启动盘点会话并消费标签流。 

using LlrpSdk;

// 1. 创建并构建读写器
await using var reader = LlrpReader.CreateBuilder("192.168.1.100")
    .WithPort(5084)
    .WithConnectTimeout(TimeSpan.FromSeconds(5))
    .Build();

// 2. 建立连接（自动探查 LLRP 1.1/1.0.1 协议版本并查询硬件能力）
await reader.ConnectAsync();

// 3. 获取基于该设备能力表生成的推荐默认配置并下发
ReaderSettingsDefaults defaults = await reader.GetDefaultSettingsAsync();
await reader.ApplySettingsAsync(defaults.Settings);

// 4. 启动托管盘点会话
await using InventorySession session = await reader.StartInventoryAsync();

// 5. 异步迭代消费标签报告
await foreach (TagReport tag in session.ReadReportsAsync())
{
    Console.WriteLine($"[天线 {tag.AntennaId}] EPC: {tag.EpcHex} | RSSI: {tag.PeakRssi} dBm");
}
生命周期提示： InventorySession 实现了 IAsyncDisposable。使用 await using 离开作用域时，SDK 会自动停止当前盘点并释放报告流。

硬件能力与参数索引 (Capabilities)

在 LLRP 协议中，RF 模式 (ModeIndex)、发射功率 (TransmitPowerIndex) 等均为数字索引。索引对应的实际速率、调制模式或 dBm 功率表均存储在 reader.Capabilities 中。 

ReaderCapabilities caps = reader.Capabilities!;

// 查看天线数量与 UTC 时钟支持
Console.WriteLine($"天线数量: {caps.MaxNumberOfAntennas}, UTC时钟: {caps.HasUtcClockCapability}");

// 查看支持的 C1G2 RF 模式表 (ModeIdentifier -> 调制/速率)
foreach (var mode in caps.RfModes)
{
    Console.WriteLine($"RF Mode {mode.ModeIdentifier}: M={mode.MValue}, Tari={mode.MinTariValue}ns");
}

// 查看发射功率表 (Index -> 实际 dBm 功率)
foreach (var pwr in caps.TxPowers)
{
    Console.WriteLine($"Power Index {pwr.Index}: {pwr.TransmitPowerDbm:F2} dBm");
}

配置与参数管理 (ReaderSettings)

ReaderSettings 提供了强类型的不可变配置模型，支持天线列表、RF 模式、Gen2 Session 以及心跳控制的编辑与校验。 

ReaderSettings defaultSettings = (await reader.GetDefaultSettingsAsync()).Settings;

// 基于默认配置进行流式修改
ReaderSettings customSettings = defaultSettings.Edit(builder => builder
    .Configuration(config => config with
    {
        Keepalive = new KeepaliveConfiguration
        {
            TriggerType = KeepaliveTriggerType.Periodic,
            IntervalMs = 5000 // 每 5 秒一次心跳
        }
    })
    .Inventory(inv => inv
        .Antennas(1, 2)            // 启用天线 1 和 2
        .Mode(modeIndex: 1000)     // 指定 RF Mode Index
        .Session(2)                // Gen2 Session = 2
        .Population(64)            // 预计标签数 64
        .ReportEveryTag()));       // 逐条上报

// 校验并应用到读写器（部署后保持停止状态）
await reader.ApplySettingsAsync(customSettings);

托管盘点与报告流 (Inventory & Stream)

SDK 支持一段式与两段式盘点启动。对于需要独占或复用配置的场景，提供了清晰的入口：

调用方式 执行行为 典型场景
StartInventoryAsync(settings) 部署指定配置并立即启动盘点 单步骤快速盘点
ApplySettingsAsync(settings) 仅下发配置并部署资源，保持停止 两段式编排 / 预置配置
StartInventoryAsync() 启动已部署或 Desired 配置 Apply 后的显式启动或恢复
StartExistingRoSpecAsync(id) 桥接运行外部/自定义 ROSpec 使用 SDK 报告管道运行 Raw 资源
报告出口互斥规则： session.ReadReportsAsync()、reader.ReadTagReportsAsync() 与 reader.TagsReported 事件是互斥的。单次盘点中首次被消费的出口拥有独占权，混用将抛出 InvalidOperationException。

盘点附加内存读取 (AttachedData)

很多 RFID 业务需要在盘存 EPC 的同时读取 TID 或 User 存储区数据。InventorySettings.AttachedData 可在盘点 ROSpec 中无缝内嵌 AccessSpec，实现单次盘点原子读取附加数据。 

var inventory = new InventorySettings
{
    AntennaIds = [1, 2],
    AttachedData = new AttachedDataOptions
    {
        Enabled = true,
        MemoryBank = 2, // 2 = TID 存储区
        WordPointer = 0,
        WordCount = 6,  // 读取前 6 字 (96 位)
        AccessPassword = "00000000"
    }
};

await using var session = await reader.StartInventoryAsync(inventory);
await foreach (TagReport tag in session.ReadReportsAsync())
{
    Console.WriteLine($"EPC: {tag.EpcHex}");
    if (tag.AccessOperationResults is { Count: > 0 } results && results[0].Success)
    {
        string tidHex = string.Join("", results[0].ReadData.Select(w => w.ToString("X4")));
        Console.WriteLine($"附加 TID: {tidHex}");
    }
}

C1G2 标签操作 (Tag Access)

支持标准 Gen2 内存读写、加锁、灭活和块擦除。SDK 会在内部协调资源并自动等待目标标签返回结果。 

// 1. 指定目标标签匹配规则 (按 EPC 匹配)
var selection = new TagSelection
{
    MemoryBank = TagMemoryBank.ElectronicProductCode,
    BitPointer = 32,
    BitLength = 96,
    Mask = Convert.FromHexString("FFFFFFFFFFFFFFFFFFFFFFFF"),
    Data = Convert.FromHexString("E28011910000000000000001")
};

// 2. 写入 User 存储区 (从 Word 0 写入 2 个字)
TagAccessResult writeResult = await reader.WriteTagMemoryAsync(new WriteTagRequest
{
    Selection = selection,
    MemoryBank = TagMemoryBank.User,
    WordPointer = 0,
    WriteData = [0x1234, 0x5678],
    AccessPassword = "00000000"
});

// 3. 锁定 User 存储区为 SecuredWrite (带密码可写)
TagAccessResult lockResult = await reader.LockTagMemoryAsync(new LockTagRequest
{
    Selection = selection,
    UserMemoryLockMode = TagLockMode.SecuredWrite,
    AccessPassword = "00000000"
});

接管策略 (ResourceTakeoverPolicy)

ResourceTakeoverPolicy 控制 SDK 下发配置前对读写器既有 ROSpec/AccessSpec 的清理边界。

默认推荐

PreserveForeign

仅清理和替换 SDK 自有保留资源 (ROSpec 14150, AccessSpec 14151)，保留其他客户端或系统创建的资源。

显式独占

ReplaceAll

向读写器发送 ID=0 删除指令，清空设备所有 ROSpec 与 AccessSpec 后再部署。仅在独占读写器时使用。

厂商扩展支持 (Vendor Extensions)

通过扩展包，无缝启用厂商专属的射频调制算法、上报字段与高级功能： 

// 启用 Impinj 扩展（Speedway / R420 等）
var reader = LlrpReader.CreateBuilder("192.168.1.100")
    .UseImpinj() // 注册 Impinj Codec 与 Reader 扩展
    .Build();

await reader.ConnectAsync();

// 启用 Impinj Serialized TID、RF 相位与高精度 RSSI 上报
var inventory = new InventorySettings().Edit(b => b
    .WithImpinj(imp => imp
        .WithSerializedTid(true)
        .WithRfPhaseAngle(true)
        .WithSearchMode(ImpinjInventorySearchMode.DualTarget)));

await using var session = await reader.StartInventoryAsync(inventory);
await foreach (TagReport tag in session.ReadReportsAsync())
{
    if (tag.Extensions?.TryGetValue("impinj.rfPhaseAngle", out var phase) == true)
    {
        Console.WriteLine($"RF 相位角: {phase}");
    }
}
