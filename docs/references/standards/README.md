# Standards Reference Placement

Use this directory for local standards references that are needed for field layout verification, conformance checks, or protocol research.

Suggested local layout:

```text
llrp-1.0.1/
llrp-1.1/
llrp-2.0/
gen2v2/
```

For each source, record its URL, download date, version or revision, and SHA-256. Protocol generation is based on machine-readable definitions; PDFs are used to verify field widths, order, choices, cardinality, and constraints.
