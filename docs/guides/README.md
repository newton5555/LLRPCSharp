# Guides

These guides describe the two application-facing entry points. Protocol
models, codecs, and generated assets belong to `LlrpNet` and are documented in
the architecture and protocol reference sections.

- [SDK API Guide](sdk-api-guide.md): use the managed `LlrpReader` API from a
  .NET application.
- [CLI User Guide](cli-user-guide.md): operate a reader with the Live Shell or
  an agent-friendly one-shot command.
- [Virtual Reader Manager](virtual-reader-manager.md): start the SDK repository's
  message-level TCP virtual reader for SDK and integration testing.
