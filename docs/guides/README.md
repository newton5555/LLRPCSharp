# Programmer’s Guides

These guides describe the two application-facing entry points. Protocol
models, codecs, and generated assets belong to `LlrpNet` and are documented in
the architecture and protocol reference sections.

- [Reader SDK Programmer’s Guide](sdk-api-guide.md): use the managed
  `LlrpReader` client from a .NET application.
- [Reader CLI User’s Guide](cli-user-guide.md): operate a reader with the Live Shell or
  an agent-friendly one-shot command.
- [Virtual Device CLI and SDK tool](virtual-device-cli.md): host one virtual
  LLRP device through the device-side CLI or public SDK facade when writing tests.
