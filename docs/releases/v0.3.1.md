## 🚀 LLRPCSharp v0.3.1

LLRPCSharp v0.3.1 是专注于 **NuGet 双包打包优化、发布自动化演进与包嵌入解耦** 的重要版本。修正了此前 v0.3.0 在发布构建与文档挂载上的遗留问题，进一步提升了 SDK 依赖集成的开箱即用体验。

---

### 📦 核心 SDK 与 NuGet 包优化 (`LlrpSdk`)

- **双包架构与依赖解耦**：
  - 调整发布方案为仅发布 **`LlrpSdk`**（主包）与 **`LlrpSdk.Extensions.Impinj`**（扩展插件包）两个核心 NuGet 包。
  - 将 `LlrpNet.Core`、`LlrpNet.Protocol` 和 `LlrpSdk.Extensions.Abstractions` 底层程序集直接打包并嵌入至 `LlrpSdk.nupkg` 的 `lib/net10.0/` 中。
  - 彻底解决了外部通过 `dotnet add package LlrpSdk` 引用时提示缺少未发布子依赖包的问题。
- **Package README 全量嵌入**：
  - 统一配置 `PackageReadmeFile` 机制，发布至 [NuGet.org](https://www.nuget.org/) 的各个包均内置 `README.md`，并在 package 页面自动渲染。

---

### 🔌 厂商扩展插件 (`LlrpSdk.Extensions.Impinj`)

- **解耦依赖**：
  - 标记底层 Protocol 与 Abstractions 项目为 PrivateAssets，NuGet 依赖仅指向主包 `LlrpSdk`，保持清晰干净的插件链条。

---

### 🛠️ CLI 产物与开发者工具链 (`tools/`)

- **CLI 压缩包挂载完整文档**：
  - 发布工作流自动将 `README.md` 与 `LICENSE` 复制并打入 `LlrpCli-v0.3.1-win64.zip`。
- **本地代码生成脚本集中化**：
  - 在 `tools/` 目录下新增 [Generate-ProtocolCode.ps1](file:///f:/Projects/LLRP/LLRPCSharp/tools/Generate-ProtocolCode.ps1) 自动化 PowerShell 脚本，支持通过 `-Target 1.0.1|1.1|Impinj|2.0` 一键按需重新生成协议 `.g.cs` 源码。
  - 新增 [tools/README.md](file:///f:/Projects/LLRP/LLRPCSharp/tools/README.md) 工具链指南。

---

### 🤖 CI/CD 发布工作流优化 (`.github/workflows/release.yml`)

- **自动生成 Release 说明与差异对比**：
  - Release 页面自动挂载项目内部归档文档（`body_path`），并自动附带全量 Git Commit 对比日志（Full Changelog）。

### 📦 资产与安装

#### SDK NuGet 包

主 SDK 包（已内联包含 Core/Protocol/Abstractions）：
```bash
dotnet add package LlrpSdk --version 0.3.1
```

Impinj 扩展插件：
```bash
dotnet add package LlrpSdk.Extensions.Impinj --version 0.3.1
```

#### Windows x64 CLI

从 [GitHub Releases](https://github.com/newton5555/LLRPCSharp/releases) 下载 `LlrpCli-v0.3.1-win64.zip`，解压即用。
