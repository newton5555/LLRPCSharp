# LLRPCSharp 2.0.4 Release Notes

> Release Date: 2026-08-27
> 正式版（非预览）。

## Reader configuration safety

- GPO output updates now remain configuration-only and no longer redeploy the
  managed inventory resource just because an output state changes.
- Idempotent cleanup recognizes the missing-resource responses used by both
  common LLRP 1.0.1 readers and Zebra readers.
- Added regression coverage proving that GPO updates do not delete the SDK's
  ROSpec or AccessSpec.

## Compatibility and package boundary

- LLRP 1.0.1, 1.1, and 2.0 SDK baselines remain available.
- `LlrpDevice.Virtual.Hosting` remains the public virtual-device entry point.
- The SDK packages `LlrpSdk`, `LlrpSdk.Extensions.Impinj`,
  `LlrpSdk.Extensions.Zebra`, and `LlrpDevice.Virtual.Hosting` are published at
  version `2.0.4`.

## Verification

- The release build and automated tests are required to pass in the release
  workflow before the packages are published.
- Physical-reader verification is run against the available reader and is
  recorded separately in the reader interoperability evidence.
