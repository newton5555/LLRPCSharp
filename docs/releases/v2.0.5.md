# LLRPCSharp 2.0.5 Release Notes

> Release Date: 2026-08-31
> 正式版（非预览）。

## Reader inventory takeover

- Added `LlrpReader.PrepareInventoryTakeoverAsync(ResourceTakeoverPolicy.ReplaceAll)`
  for applications that must explicitly silence an already-running inventory before
  querying or deploying a replacement.
- The new entry point requires `ReplaceAll` and uses LLRP identifier-zero deletion
  for all standard ROSpec and AccessSpec resources; the default `PreserveForeign`
  workflow remains non-destructive toward foreign resources.
- Managed `StartInventoryAsync` and `ApplySettingsAsync` now preflight after the
  selected cleanup phase, so an exclusive takeover does not query the resource graph
  before the device has been silenced.

## Diagnostics and compatibility

- Increased the default high-level request timeout from 10 to 30 seconds for slower
  readers while keeping connection and frame-assembly timers unchanged.
- Timeout exceptions now include the request message ID, request type, expected
  response type, and a clear missing-response diagnosis.
- Added regression coverage for cleanup ordering, explicit takeover policy enforcement,
  and timeout diagnostics.

## Package boundary

- `LlrpSdk`, `LlrpSdk.Extensions.Impinj`, `LlrpSdk.Extensions.Zebra`, and
  `LlrpDevice.Virtual.Hosting` are published at version `2.0.5`.

## Verification

- The release build and automated tests are required to pass in the release workflow
  before the packages are published.
- Physical-reader verification is run against the available reader and recorded
  separately in the reader interoperability evidence.
