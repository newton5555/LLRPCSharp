# LLRPCSharp 2.0.1 Release Notes

> Release Date: 2026-08-20
> 正式版（非预览）。

## Capability-aware reader defaults

- `GetDefaultSettingsAsync()` now builds the standard RF baseline from the connected
  reader's advertised capabilities instead of relying on a fixed generic shape.
- The baseline selects usable antennas, the first RF mode and receive sensitivity,
  the highest advertised transmit power, and the first usable hop/channel entry.
- Impinj, Zebra, and Seuic extensions can layer verified model/firmware defaults on
  top of that baseline; unknown profiles remain conservative and do not invent vendor
  parameters.
- The verified Impinj R420 profile now contributes typed reader defaults and enables
  optional report fields only when the capability catalog confirms them.

## Compatibility and package boundary

- LLRP 1.0.1, 1.1, and 2.0 SDK baselines remain compatible with 2.0.0.
- `LlrpDevice.Virtual.Hosting` remains the public virtual-device entry point; the
  package version is `2.0.1`.
- The SDK packages `LlrpSdk`, `LlrpSdk.Extensions.Impinj`,
  `LlrpSdk.Extensions.Zebra`, and `LlrpDevice.Virtual.Hosting` are published at
  version `2.0.1`.
