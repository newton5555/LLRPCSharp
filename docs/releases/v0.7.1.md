# LLRPCSharp 0.7.1 Release Notes

> Release Date: 2026-08-04

## 🐛 Bug Fixes

- **`LlrpSdk.Extensions.Impinj` 打包修复**:`LlrpNet.Protocol.Impinj.dll` 现在内嵌进 Impinj 扩展包的 `lib/net10.0`(与 `LlrpSdk` 内嵌 `LlrpNet.Core`/`LlrpNet.Protocol` 的做法一致),nuspec 不再依赖独立发布的 `LlrpNet.Protocol.Impinj` 包。`LlrpSdk.Extensions.Impinj` 仍正常依赖 `LlrpSdk`(NuGet)。

## 📦 Package Version

- `LlrpSdk`: `0.7.1`
- `LlrpSdk.Extensions.Impinj`: `0.7.1`
- Target Framework: `.NET 10.0` / `C# 14`
