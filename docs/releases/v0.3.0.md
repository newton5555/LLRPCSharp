## 🚀 LLRPCSharp v0.3.0

LLRP 1.0.1 / 1.1 SDK 与 CLI Studio 的全新体验与发布自动化版本，重点落地 Live Shell 草稿工作流、交互式向导、受控配置写入修正、CLI `tag` 全量命令对齐，以及 GitHub Actions Trusted Publishing 自动化 CI/CD 流程。

### ✨ 核心 SDK (`LlrpSdk`)

- **受控配置写入修正**：修正托管 `ApplySettingsAsync` 事务处理逻辑，执行底层 `SET_READER_CONFIG` 配置写入后不再误触发 `StateUnknown` 状态，确保能够连贯部署 SDK 保留 ROSpec。
- **与状态感知的 Filter 匹配**：要求 `InventorySelectFilter.StateAwareAction` 与 `InventorySettings.StateAwareSingulation` 同时存在；在硬件具备 `CanDoTagInventoryStateAwareSingulation` 时完整支持，否则提供安全校验与报错。
- **C1G2 扩展标签访问 API**：补充完整 `LockTagMemoryAsync`、`KillTagAsync`、`BlockEraseTagMemoryAsync` API 支持，与 `ReadTagMemoryAsync` / `WriteTagMemoryAsync` 保持统一的自动 ROSpec 生命周期管理体验。
- **能力快照与物理参数**：暴露 Reader 能力快照，包含完整的 TxPowers、RxSensitivities、TxFrequencies、HopTables 和门控能力标志。

### 🔌 厂商扩展与 Contributor

#### Impinj (`LlrpSdk.Extensions.Impinj`)
- **同值写入与回读验证**：在 Impinj R420（固件 6.4.1.240）完成 GPI debounce、Link Monitor、Report Buffer 和 AccessSpec 配置的同值 `ApplySettingsAsync()` / `QuerySettingsAsync()` 回读闭环验证。
- **TagReport 扩展属性**：盘点模式下支持 `impinj.serializedTid`、`impinj.rfPhaseAngle` 和 `impinj.peakRssi` 字段投影。
- **Profile 与事实暴露**：支持将硬件 Facts 暴露为只读信息（`impinj.facts`），将可写属性暴露为强类型扩展模型（`impinj.configuration`）。

#### Seuic (`LlrpSdk.Extensions.Seuic`)
- **自动天线与频点映射**：根据识别的硬件能力表自动将物理天线和 Rx/Tx/Hop/Channel 直接配置到标准模型中。

### 🖥️ CLI Studio (`LlrpCli`)

- **草稿优先盘点配置**：
  - `settings draft show|load|save|reset` 用于离线或在线构建与管理盘点草稿；
  - `settings draft wizard` 提供交互式 Prompts 引导编辑体验；
  - `settings draft apply --yes` 能够将当前草稿一键部署至读写器；
  - `settings show --tree` 通过 Spectre.Console Tree 优雅展示多层配置结构。
- **全量 `tag` 指令集**：
  - 支持 `tag read`、`tag write`、`tag lock`、`tag erase`、`tag kill` 与 `tag sequence`；
  - 所有破坏性标签写入或修改指令均需要显式 `--yes` 确认，省略时提供 Dry-run 执行计划提示。
- **连接门控与自动补全**：
  - 动态补全提示包含连接状态检查，末尾空格支持自动候选项补全。

### 🤖 CI/CD 自动化与 Trusted Publishing

- **GitHub Actions Release 工作流**：引入 `.github/workflows/release.yml`；在推送 `v*` 标签或手动触发时自动执行编译、测试、打包。
- **NuGet Trusted Publishing (OIDC)**：支持免 API Key 的密码学认证，安全自动推送 `.nupkg` 至 [NuGet.org](https://www.nuget.org/)。
- **GitHub Release 自动挂载**：打包产物与 `LlrpCli-v0.3.0-win64.zip` 自包含可执行包将自动生成并挂载为 GitHub Release 资源。

