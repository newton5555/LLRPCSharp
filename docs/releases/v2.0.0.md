# LLRPCSharp 2.0.0 Release Notes

> Release Date: 2026-08-19
> 正式版（非预览）。

## Public virtual-device hosting package

- 将 `LlrpDevice.Virtual.Hosting` 定为虚拟设备服务的对外顶层 NuGet 包。
- `IVirtualDeviceHost`、`VirtualDeviceHostOptions`、`VirtualDeviceProfiles` 和
  `VirtualLlrpDeviceHost.Create(...)` 组成应用侧稳定入口；客户端不需要直接引用
  `LlrpDevice.Server`、`LlrpDevice.Virtual` 或设备端协议项目。
- Hosting 包内置标准 LLRP 1.0.1 与 Impinj R420 profile，并携带其设备端实现和协议运行时，
  便于 WPF、CLI 与自动化测试以单一包接入。
- 原有低层 Hosting 类型保留为迁移兼容路径；新应用应优先使用 Hosting-level API。

## SDK and device capabilities

- 保持 LLRP 1.0.1、1.1 和 2.0 协议/SDK 基线，以及 Impinj、Zebra 扩展包。
- 保持通用 LLRP Device Server、确定性 Virtual Device、标准 Tag Access、生命周期、
  客户端连接和报文观察能力。
- `LlrpVirtualDevice.Cli` 继续复用同一 Hosting facade，标准设备和 Impinj R420 模拟设备
  的启动配置保持兼容。

## Package boundary

- 直接面向应用的虚拟设备服务包：`LlrpDevice.Virtual.Hosting`。
- `LlrpDevice.Server`、`LlrpDevice.Virtual`、`LlrpDevice.Virtual.Impinj` 和底层协议程序集
  是 Hosting 的实现组成；需要扩展能力时再使用相应的 SDK/扩展包。
