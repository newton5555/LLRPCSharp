# LLRPCSharp 1.5.0 Release Notes

> Release Date: 2026-08-18
> 正式版（非预览）。

## Virtual Device SDK 与 CLI

- 完成单台 Virtual Device 的 SDK/Hosting 生命周期门面，支持创建、启动、停止、
  重启和状态观察。
- 完成通用 LLRP Device Server 与确定性 Virtual Device 的 1.0.1 设备闭环，覆盖
  ROSpec、AccessSpec、报告、事件、Hold/Release 和标准 Tag Access。
- 增加独立的 `LlrpVirtualDevice.Cli`，与客户端 `LlrpCli` 分离，支持版本化设备配置、
  能力档案、寻卡数据源和 `run`/`live` 工作流。
- 改进 Virtual Device 的标签采样行为，使盘点报告更接近实际设备的多轮采样特征。

## CLI 与诊断

- 增强 pcapng 报文解码路径，支持 Live Shell 和离线工具按消息类型筛选。
- 统一客户端 CLI 与 Virtual Device CLI 的职责边界，保持协议版本显式选择。

## 修复与兼容性

- 修正 Impinj 配置索引的 base-1 语义。
- 完善 LLRP 1.0.1 Virtual Device 能力档案和默认 RF/标签数据源。

## 验证

- Release 构建：0 警告、0 错误。
- 自动化测试：519/519 通过，0 失败、0 跳过。
- Impinj R420（192.168.40.87，固件 6.4.1.240）：LLRP 1.0.1 连接、能力/配置读取和
  inventory 标签报告验证通过。

## 已知限制

- LLRP 2.0 真实设备互操作仍未完成完整验收。
- Zebra 扩展仍有部分字段需要逐参数真机抓包标定。
