## 🚀 LLRPCSharp v0.4.0

LLRPCSharp v0.4.0 是面向 **协议扩展分层与 Impinj 扩展能力完善** 的版本。该版本继续保持 LLRP 1.0.1 与 Impinj 默认扩展作为当前主线交付目标，同时把底层协议资产与 SDK 扩展插件的边界进一步拆清。

---

### 🧱 协议与 SDK 分层

- **源码布局整理**：
  - 将 `LlrpNet.Core`、`LlrpNet.Protocol`、`LlrpNet.ProtocolModel` 和协议生成器移动到 `src/LlrpNet/` 下，解决方案结构与文档入口同步更新。
  - 将 `LlrpSdk` 内部代码按 `Reader`、`Protocol`、`Inventory`、`Reports`、`Resources`、`Settings` 与 `TagAccess` 分区组织，便于后续维护。
- **Impinj 协议资产独立化**：
  - 新增 `LlrpNet.Protocol.Impinj` 项目，承载 Impinj 生成消息、参数、枚举、Codec 与 Registry Module。
  - `LlrpSdk.Extensions.Impinj` 专注高层 SDK 插件能力；Raw 协议用户可以直接引用 Impinj 协议模块。

---

### 🔌 Impinj 扩展

- **Inventory Report 控制增强**：
  - `ImpinjInventoryReportOptions` 与 `ImpinjInventoryControlOptions` 进一步拆分和扩展。
  - 支持更清晰地表达 Serialized TID、RF Phase、Peak RSSI、优化读取、Doppler、TxPower、XPC、CR Handle、ID、Enhanced Integra、Endpoint IC 等报告控制项。
- **扩展 TagReport 入口**：
  - 新增 `ImpinjTagReportExtensions`，简化从 `TagReport.Extensions` 读取 Impinj 扩展字段的调用。
- **测试覆盖补充**：
  - 新增独立 `LlrpNet.Protocol.Impinj.Tests`。
  - 补充 Impinj Protocol Module、Extension 激活与 Inventory 控制选项相关测试。

---

### ⚙️ 轻量托管 Settings API

- `ReaderSettings.Create/Edit` 与 `InventorySettings.Create/Edit` 提供可选 Fluent Builder，直接生成现有不可变 record，高级用户仍可使用对象初始化器和 `with` 深入配置。
- 新增无副作用 `ValidateSettingsAsync()`，以结构化诊断返回标准字段、协议版本、Reader Capabilities 和厂商扩展问题。
- `ApplySettingsAsync(settings)`、`StartAsync(settings)` 与 `StartInventoryAsync(settings)` 在资源操作前执行相同校验，避免无效配置先清理 Reader 资源。
- Impinj 扩展新增 `.Impinj(...)` 强类型 Builder，常用调用不再需要手写 `impinj.inventoryReport` / `impinj.inventoryControl` Key。

### 🛠️ 工具链与文档

- **CLI Settings 契约重构**：
  - Live Shell 收敛为 `settings show|edit|validate|apply|load|save|discard`，明确区分只读、CLI 本地草稿与设备写入；旧命令不保留兼容别名。
  - 新增分组 Settings 编辑器，覆盖天线/RF、Singulation、报告、Filters、触发器、Attached Data、Reader Configuration 与 Impinj 扩展；高级用户仍可编辑完整 JSON。
- **一次性寻卡命令**：
  - 新增根级 `inventory <host> ... --yes`，支持 Settings 文件、限定时长、协议/厂商策略以及 JSON/Table 输出，面向 Agent、脚本与人工快速验收。
  - 根级 `inventory` 与 Live Shell 的 `inventory start|stop|status` 共用 `ManagedSettingsWorkflow` 和 SDK 校验/Apply 路径，不维护第二套配置逻辑；结束时自动停止并清除托管 Inventory 资源。

- **协议生成脚本适配新目录**：
  - `tools/Generate-ProtocolCode.ps1` 更新为新的 `src/LlrpNet/` 布局与 Impinj 协议项目输出。
  - `tools/Verify-SourceEncoding.ps1` 增强源文件编码检查。
- **文档同步**：
  - 更新 `docs/status.md`、`docs/roadmap.md`、`docs/architecture/source-structure.md` 与协议扩展指南，反映当前真实项目结构与未完成边界。
  - 新增协议层与扩展层解耦计划文档。

### 📦 资产与安装

#### SDK NuGet 包

主 SDK 包：
```bash
dotnet add package LlrpSdk --version 0.4.0
```

Impinj SDK 扩展插件：
```bash
dotnet add package LlrpSdk.Extensions.Impinj --version 0.4.0
```

#### Windows x64 CLI

从 [GitHub Releases](https://github.com/newton5555/LLRPCSharp/releases) 下载 `LlrpCli-v0.4.0-win64.zip`，解压即用。
