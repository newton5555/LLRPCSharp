# LLRPCSharp v0.5.0

LLRPCSharp v0.5.0 is the documentation and cross-platform distribution
preparation release. It keeps the existing two NuGet packages and expands the
CLI release archives beyond Windows.

## Documentation

- Reorganized the root README around the three project layers:
  `LlrpNet`, `LlrpSdk`, and `LlrpCli`.
- Documented the modernization of the traditional LTK.NET definition-driven
  model for current .NET applications.
- Reduced the user-facing SDK and CLI guides to the managed Reader workflow and
  the Live Shell workflow.
- Consolidated current status, roadmap, architecture, ADR, acceptance, and
  protocol reference entry points.
- Removed obsolete intermediate design specifications from the committed docs.

## CLI Distribution

The release workflow publishes self-contained CLI archives for:

- Windows `win-x64`
- Linux `linux-x64`
- macOS Intel `osx-x64`
- macOS Apple Silicon `osx-arm64`

## NuGet Packages

Only these existing packages are published:

```text
LlrpSdk
LlrpSdk.Extensions.Impinj
```

## Verification

The release workflow must pass solution build, tests, generated-source encoding
verification, and package/archive creation before the GitHub Release is created.
