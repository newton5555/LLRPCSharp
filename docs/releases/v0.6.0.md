# LLRPCSharp 0.6.0 Release Notes

> Release Date: 2026-08-04

## 🌟 Highlights & Major Improvements

- **Icon & Visual Identity Redesign**:
  - Brand-new modern vector icon (`llrpcsharp-icon.svg`), high-resolution PNG, and multi-size ICO formats.
  - Automatically configured `<PackageIcon>` in `Directory.Build.props` for official NuGet packaging.

- **Public Documentation Overhaul**:
  - Fully updated [README.zh.md](../../README.zh.md) and [README.md](../../README.md) with simplified vertical architecture diagrams and practical quick-start workflows.
  - Revamped [SDK API Guide](../guides/sdk-api-guide.md) and [CLI User Guide](../guides/cli-user-guide.md).
  - Explicitly mapped `reader.Capabilities` to numeric parameter indices (RF Mode Index & TransmitPowerIndex).

- **SDK & Protocol Enhancements**:
  - Solidified LLRP 1.0.1 and 1.1 protocol negotiation baselines.
  - Strongly-typed Impinj extension pipeline (`UseImpinj()`) for TID, Phase Angle, and Peak RSSI.
  - Cleaned up agent operational guidelines (`AGENTS.md`) and standardized the version release workflow.

## 📦 Package Version

- `LlrpSdk`: `0.6.0`
- Target Framework: `.NET 10.0` / `C# 12`
