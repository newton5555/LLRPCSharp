# LLRPCSharp 1.2.0 Release Notes

> Release Date: 2026-08-07
> 正式版（非预览）:NuGet 包版本与 GitHub Release 均不标记 prerelease。

## ✨ 新能力（LLRP 1.0.1 完成度收尾）

- **`CLOSE_CONNECTION` 接收侧**:消息泵识别设备主动关闭,best-effort 回
  `CLOSE_CONNECTION_RESPONSE`,`ConnectionChanged` 携带
  `DeviceInitiatedClose`,应用可区分"设备主动关闭"与"网络故障"。
- **`ENABLE_EVENTS_AND_REPORTS` 重连放行**:重连后若设备配置了
  `HoldEventsAndReportsUponReconnect=true`,SDK 在状态同步后发送 ENABLE
  释放被挂起的事件/报告（内部逻辑,不新增公开 API）;Impinj R430 真机验证。
- **LLRP 标准能力门控投影到 `ReaderCapabilities`**:
  - `SupportsClientRequestOpSpec`（客户端请求式访问）:R430 固件 6.4.1.240
    实测拒绝 `ClientRequestOpSpec`,SDK 不接线、仅提供门控
  - `CanDoRfSurvey`（RF 调查）:R430 实测 false,Impinj 设备普遍不支持
- **`ReaderExceptionOccurred` 事件**:暴露 Reader 内部异常（ReaderExceptionEvent,
  Message + ROSpec/SpecIndex/天线/AccessSpec 上下文）,1.0.1/1.1 均接线。
- **`TagReport.PcBits`**:投影 `C1G2_PC`（EPC 长度/编码类型信息,变长 EPC
  场景必需）,配合 `IncludePcBits` 请求。

## 🛠 测试与工具

- **修复 `LlrpNet.ProtocolGenerator.Tests` 本地卡死**:子进程管道从
  `ReadToEndAsync` + 同步 `WaitForExit` 改为事件驱动排空,9 个测试 5 秒通过
  （此前本地整套测试跑不完）。
- **`LlrpSdk.Hardware.Tests` 新增真机用例**:hold=true 重连报告恢复
  （Impinj R430,固件 6.4.1.240 验证通过）。
- **探针工具 `tools/LlrpSdk.Probe.ClientRequestOp`**:实测 CLIENT_REQUEST_OP
  支持矩阵,可换 IP 复测其他型号。
