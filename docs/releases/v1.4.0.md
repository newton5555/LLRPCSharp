# LLRPCSharp 1.4.0 Release Notes

> Release Date: 2026-08-14
> 正式版（非预览）。

## CLI 改造 (WP1-WP8)

### 版本/厂商对齐 (WP1)
- --llrp 增加 2.0（修 2->Force20 错映射，补别名 101/11/20）
- --vendor 增加 zebra
- Helpers.CreateRegistry() 注册 1.0.1/1.1/2.0 + Impinj + Zebra 全模块
- encode 加 --llrp 版本感知，消息目录单源（Helpers.CreateEncodeMessage）
- banner 版本号取程序集版本

### Settings 收缩 (WP2)
- 子命令 7->5：show/validate/apply/edit/save
- 移除 defaults/load（不保留别名），apply --defaults --yes 吸收原 defaults
- ManagedSettingsWorkflow.DeployAsync 消除双校验

### 一段式盘点 (WP3)
- inventory start --defaults|--settings <file> 部署+启动一段式
- 与 one-shot inventory 共用 DeployAsync 核心

### Manual 命令 (WP4)
- resources manual enter/exit -> manual on/off/status
- ManualModeGuard.TryAutoExitManualModeAsync：托管调用自动 off（有资源确认/无资源静默）
- manual on 自动 sync 前置

### Tag Sequence 结构化 (WP5)
- tag sequence 支持 --read/--write/--erase/--lock/--kill 结构化旗标（保留 --op 兼容）

### 消重 (WP6)
- D1：删除死代码 LlrpFrameAnalyzer.cs（从未接线）
- D2：TagAccessCliRequest.ParseHex 统一到 Helpers.ParseHex
- D3：standalone 与 Live Shell 的 inspect/decode/validate 合并到 OfflineProtocolTool 共享核
- D4：encode 消息目录单源（Helpers.CreateEncodeMessage）

### 编辑器增强 (WP7)
- E2：能力交叉引用（编辑 RF 索引时就地显示 reader.Capabilities 表）
- E1：厂商扩展泛化（Impinj + Zebra 分支，删除硬编码 is ImpinjReaderExtension）
- E4：内联校验（population/ReportEveryN 加 .Validate）
- E3：变更 diff 预览（RenderReviewDiff）
- E5：事件开关改 MultiSelectionPrompt 一次勾选
- E6：导航增强（编号菜单 + Discard 未保存确认）
- E7：JSON 导入（ImportJson 加载+校验）

### 文档同步 (WP8)
- docs/status.md、docs/roadmap.md、docs/guides/cli-user-guide.md、docs/architecture/llrpcli-optimization-plan.md 全部同步

## 新增根级在线一次性命令

- llrp status <host> -- 连接 -> 身份/协商/扩展 -> 断开，默认 JSON
- llrp caps <host> -- 连接 -> GET_READER_CAPABILITIES -> 断开，默认 JSON
- 均支持 --llrp/--vendor/--output json|table
