# LLRPCSharp 0.8.0 Release Notes

> Release Date: 2026-08-05

## 🐛 Bug Fixes

- **Impinj 扩展参数位置修复(真机 398 根因)**:官方 `Impinjdef.xml`(Impinj LTK 10.30.0.0)声明 `ImpinjFixedFrequencyList`、`ImpinjReducedPowerFrequencyList`、`ImpinjLowDutyCycle` 的 `allowedIn = C1G2InventoryCommand`,而此前 SDK 将它们发在 `SET_READER_CONFIG` 顶层,真机会拒绝(`M_UnsupportedParameter` / 错误码 398)。三个参数已按 `ImpinjInventorySearchMode` 的模式迁移到 inventory 命令级(`ImpinjInventoryControlOptions` / `impinj.inventoryControl`),随 `C1G2InventoryCommand` 发送并读回。

## ⚠️ Breaking Changes

- **`ImpinjReaderConfiguration` 移除 `FixedFrequency` / `ReducedPowerFrequency` / `LowDutyCycle` 字段**(reader 配置级)。对应能力改由 `ImpinjInventoryControlOptions`(inventory 命令级)承载,新增 builder 方法:
  - `ImpinjInventorySettingsBuilder.FixedFrequency(mode, channelList)`
  - `ImpinjInventorySettingsBuilder.ReducedPowerFrequency(mode, channelList)`
  - `ImpinjInventorySettingsBuilder.LowDutyCycle(mode, emptyFieldTimeoutMs, fieldPingIntervalMs)`
  - 此前经 `ReaderSettings.Configuration.Extensions["impinj.configuration"]` 设置这三个字段的应用需要迁移到 inventory 层。
- 注:`ImpinjReaderConfiguration.InventorySearchMode` 已在 0.7.2 移除(同样迁移到 inventory 命令级),`ImpinjInventorySettingsBuilder.SearchMode(...)` 承载。

## 📚 Documentation

- 新增 `docs/references/impinj/llrp-extension-alignment.md`:SDK 全部 Impinj 自定义参数与官方 `Impinjdef.xml` `allowedIn` 的对齐审计表(发送位置、判定、修复记录)。
