## 🚀 LLRPCSharp v0.2.0

LLRP 1.0.1 SDK 与 CLI Studio 的功能完善版本，重点完成 Live Shell 工作流、厂商扩展接入与盘点调试体验优化。

### ✨ 核心 SDK (`LlrpSdk`)

- **协议与连接**：支持 LLRP 1.0.1，并提供 LLRP 1.1 版本协商、自动回退和强制版本策略。
- **托管盘点流**：提供 `LlrpReader` 高层生命周期 API：`StartAsync()`、`StopAsync()`、`InventoryAsync()`、`ReadTagReportsAsync()` 与 `TagsReported`。
- **完整资源清理**：SDK 托管盘点停止时执行 `STOP_ROSPEC`、`DISABLE_ROSPEC`、`DELETE_ROSPEC`，并清理关联的 Attached Data AccessSpec。
- **配置与盘点意图分离**：
  - `ReaderSettings` 表示一次盘点意图；
  - `QueryConfigurationAsync()` 查询设备当前配置；
  - `ApplyConfigurationAsync()` 显式应用配置变更。
- **标签访问 API**：支持标准 C1G2 Memory Read、Write、Lock、Kill、BlockErase，以及组合 Tag Access 序列。
- **高级资源服务**：提供 `RoSpecs` 与 `AccessSpecs` 显式管理入口，适合需要直接控制底层 LLRP 资源的场景。
- **硬件事件与能力表**：支持 Reader Capabilities、Tx/Rx 功率索引表、GPIO、Keepalive、Report Buffer 等标准能力与事件。

### 🔌 厂商扩展

#### Impinj (`LlrpSdk.Extensions.Impinj`)

- **主动扩展激活**：`UseImpinj()` 使用两阶段能力查询完成身份识别、`IMPINJ_ENABLE_EXTENSIONS` 激活与完整能力快照读取。
- **Tag Report 扩展字段**：支持 Serialized TID、RF Phase Angle、Peak RSSI。
- **设置 Contributor**：可查询 Impinj 区域、温度、GPI 防抖、Report Buffer、AccessSpec 等厂商配置摘要。
- **版权说明**：包内包含基于 Impinj Octane LTK Definition Files 的协议定义衍生资产及许可证说明。

#### Seuic (`LlrpSdk.Extensions.Seuic`)

- **Seuic UF40 兼容 Profile**：按厂商 ID、型号和协议版本自动匹配。
- **标准协议兼容**：不依赖 Seuic 私有 Message 或 Parameter；通过标准 AISpec 中的天线、RF Receiver、RF Transmitter、Hop/Channel 与 Singulation 参数提供兼容默认值。
- **核心解耦**：厂商型号逻辑位于扩展中，SDK 核心仅提供通用 Inventory Profile Contributor 扩展点。

### 🖥️ CLI Studio (`LlrpCli`)

- **Live Shell 收敛**：所有读写器在线操作统一在连接后的交互式 Live Shell 中完成；根命令保留 `inspect`、`decode`、`validate`、`encode` 等离线协议工具。
- **盘点草稿**：
  - `inventory settings show|set|load|save|reset` 管理下一次盘点意图；
  - `inventory start` 消费草稿快照；
  - 临时天线覆盖不会修改会话草稿。
- **盘点与监控模式**：
  - `inventory start --monitor live`：按 EPC 聚合标签表格；
  - `inventory start --monitor frames`：显示原始 LLRP TX/RX 帧；
  - `inventory start --monitor-duration 30`：监控 30 秒后返回 Prompt，盘点继续运行；
  - `inventory stop`：停止并清理 SDK 托管盘点。
- **报文调试体验**：
  - 非标签 LLRP 帧统一记录和展示；
  - Live 标签表格期间，非标签帧会暂存，并在退出表格后按顺序渲染；
  - 标签报告在 Live 模式聚合显示，在 Frames 模式逐帧显示。
- **智能输入与补全**：
  - 空 Prompt 显示推荐的下一步操作；
  - 输入时直接显示匹配命令、子命令和选项；
  - `Tab` 接受建议或循环候选，`Shift+Tab` 反向循环。
- **厂商模式选择**：

  ```text
  connect <host> [port] --vendor auto|impinj|seuic|none
  ```

  - `auto`：连接后按设备身份自动匹配扩展；
  - `impinj`：仅加载 Impinj 扩展；
  - `seuic`：仅加载 Seuic 扩展；
  - `none`：纯标准 LLRP 模式。

### 📦 资产与安装

#### SDK NuGet 包

核心 SDK：[LlrpSdk · NuGet.org](https://www.nuget.org/packages/LlrpSdk/)

```bash
dotnet add package LlrpSdk --version 0.2.0
```

Impinj 扩展：[LlrpSdk.Extensions.Impinj · NuGet.org](https://www.nuget.org/packages/LlrpSdk.Extensions.Impinj/)

```bash
dotnet add package LlrpSdk.Extensions.Impinj --version 0.2.0
```

> NuGet 安装命令仅在对应 `.nupkg` 已发布至 NuGet.org 或配置的私有源后可用。

#### Windows x64 CLI

下载 `LlrpCli-v0.2.0-win64.zip`，解压后运行：

```text
LlrpCli.exe
```

该 ZIP 为 Windows x64 self-contained 发布包，无需预先安装 .NET Runtime。
