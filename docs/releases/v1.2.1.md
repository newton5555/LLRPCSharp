# LLRPCSharp 1.2.1 Release Notes

> Release Date: 2026-08-11
> 正式版（非预览）: NuGet 包版本与 GitHub Release 均不标记 prerelease。

## 🐛 修复

- 修复 Reader 级配置查询与回写时丢失 `RFTransmitter.HopTableID` 的问题。
  `AntennaConfigurationSettings.HopTableId` 现在会从设备快照完整映射，并在
  `SET_READER_CONFIG` 时按原值写回；LLRP 1.0.1 与 1.1 Adapter 行为一致。
- 增加标准 LLRP 读写器的回写一致性测试，覆盖查询、应用和再次查询的跳频表、
  信道及发射功率字段。
- CLI Settings 保持无草稿的简化流程，新增 `settings apply <file> --yes` 和
  `settings defaults --yes`，应用设置后仍需单独执行 `inventory start`。

## ✅ 验证

- 解决方案构建与自动化测试通过。
- 标准 LLRP 设备 `192.168.40.88` 真机验证通过：查询 Reader 级天线配置后以
  相同值回写，`HopTableID`、`ChannelIndex` 和 `TransmitPower` 保持一致。
- 标准 LLRP 设备真机盘点冒烟通过，收到标签并完成托管 ROSpec 清理。
