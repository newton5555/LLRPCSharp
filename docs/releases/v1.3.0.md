# LLRPCSharp 1.3.0 Release Notes

> Release Date: 2026-08-12
> 正式版（非预览）: NuGet 包版本与 GitHub Release 均不标记 prerelease。

## 新能力

- CLI Live Shell 增强 Reader 配置检查能力：`status` 会展示更完整的 Reader
  配置、ROSpec 和 AccessSpec 信息，便于人工测试时直接确认设备当前状态。
- CLI Settings 与 Inventory 流程继续保持简洁入口，补充现有设备配置检查、
  settings 应用和 inventory 启动之间的操作说明。
- SDK 托管 Inventory 增加配置归一化路径，减少不同 Reader 固件对 ROSpec
  可选字段和默认值处理差异带来的启动失败。

## 修复与兼容性

- 加固 `InventorySession` 报告分发：托管盘点报告在 Reader 省略可选
  `ROSpecID` 时仍可被当前 session 正确接收。
- 改善 ROSpec 兼容性：应用层设置会经过统一归一化后再编译为 1.0.1 / 1.1
  协议对象，降低跨设备行为差异。
- Virtual Reader 增补配置与报告模拟能力，用于覆盖真实设备上暴露出的边界场景。
- CI / Release workflow 明确只运行自动化和虚拟测试项目，不在远端执行
  `LlrpSdk.Hardware.Tests` 真机验收。

## 文档

- 更新 CLI 用户手册，说明 Live Shell 中 `status`、`caps`、`settings`、
  `inventory` 的推荐使用路径。
- 更新 SDK API 文档，补充托管 Inventory 与 Reader 配置行为说明。
- 同步 `docs/status.md`、showcase 和架构文档中的当前能力边界。

## 验证

- 解决方案构建与自动化测试需在发布前通过。
- 发布前仍需执行本地真机冒烟：
  `dotnet run --project tools/LlrpSdk.LiveSmoke -- <real-reader-ip> --inventory`
