# LLRPCSharp 0.9.0 Release Notes

> Release Date: 2026-08-07

## ♻️ 重构与约定

- **删除 `GlobalAliases.cs` 全局 using 别名桥**`:GlobalAliases.cs` 历史上一并被注入所有
  项目(135+ 文件),把旧手写名(`Keepalive`、`RoSpec`、`GetReaderCapabilities`…)
  映射到生成器标准名(`KEEPALIVE`、`ROSpec`、`GET_READER_CAPABILITIES`…)。现已删除,
  旧名改为**文件级 using 别名**,并从 `Directory.Build.props` 移除注入块。
- **多版本代码约定写入 `AGENTS.md`**:双版本文件禁止裸版本命名空间 using,必须用
  `V101Messages/V101Parameters/V101Enumerations`(1.0.1)与 `V11*`(1.1)前缀别名;
  禁止旧驼峰别名;禁止默认版本路径;新增版本(2.0)加 `V20*` 别名遵循同规则。
- **`LlrpReader` 协议类型版本化**:所有 LLRP 1.0.1 类型引用显式加 `V101*` 前缀,
  与既有 `V11*` 对称。公共 API 兼容。

## ⚠️ Breaking Changes

- **`ReaderSettingsSnapshot` 命名对齐 LLRP 资源模型**:
  - `InventorySnapshot` → `ManagedRoSpecSnapshot`(RO 域,来自 `GET_ROSPECS`)
  - `ReaderSettingsSnapshot.Inventory` → `ManagedRoSpec`(与 `Settings` 配置域对称)
  - `ManagedRoSpecSnapshot.Settings` → `Inventory`(与配置域 `Settings.Inventory`
    同概念同名;两者是同一实例的同引用)
  - 影响:凡读取 `QuerySettingsAsync().Inventory` / 类型 `InventorySnapshot` 的
    应用需同步改名(如 `snapshot.Inventory` → `snapshot.ManagedRoSpec?.Inventory`)。
- 若此前使用旧名 `InventorySnapshot` 或 `snapshot.Inventory`,请迁移(见
  `docs/guides/sdk-api-guide.md` 更新用法)。
