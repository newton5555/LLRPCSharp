# LLRPCSharp 0.7.2 Release Notes

> Release Date: 2026-08-05

## 🐛 Bug Fixes

- **接收灵敏度(RX)修正**:`RxSensitivityEntry` 不再把 `ReceiveSensitivityValue` 除以 100 标成 dBm。按 LLRP 1.0.1/1.1 规范,该字段是相对最大灵敏度的整数 dB 偏移(0 dB = 最灵敏),不是 dBm 值、也非 ×100 编码。新增 `ReceiveSensitivityDb` 直接暴露偏移;新增 `ReaderCapabilities.MaximumReceiveSensitivityDbm` 透传 LLRP 1.1 的 `MaximumReceiveSensitivity` 原始值(LLRP 1.0.1 为 `null`),绝对灵敏度组合(`最大灵敏度 + 偏移`)留给应用层。CLI `caps` 命令的 RX 表同步改为显示 `dB offset`,LLRP 1.1 下额外显示最大灵敏度(dBm)。

## ✨ Features

- **`ImpinjInventorySearchMode` 迁移到 inventory 命令级**:`InventorySearchMode` 从 reader 配置级(`ImpinjReaderConfiguration`,随 `SET_READER_CONFIG` 发送)移到 inventory 命令级(`ImpinjInventoryControlOptions`,随 `C1G2InventoryCommand` 发送),与 Impinj 自定义参数的挂载位置一致。新增 `ImpinjInventorySettingsBuilder.SearchMode(...)`;`ImpinjReaderConfiguration.InventorySearchMode` 移除。
