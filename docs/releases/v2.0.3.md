# LLRPCSharp 2.0.3 Release Notes

> Release Date: 2026-08-22
> 正式版（非预览）。

## Managed and expert resource control

- Separates managed desired state from the reader's observed resource snapshot,
  so raw/expert operations no longer silently overwrite the managed intent.
- Adds explicit resource takeover policy: managed deployment preserves foreign
  ROSpec/AccessSpec resources by default and supports an opt-in `ReplaceAll`
  policy when full ownership is required.
- Unifies the managed and expert SDK control planes while preserving the existing
  managed Reader lifecycle and resource services.

## Compatibility and package boundary

- LLRP 1.0.1, 1.1, and 2.0 SDK baselines remain available.
- `LlrpDevice.Virtual.Hosting` remains the public virtual-device entry point.
- The SDK packages `LlrpSdk`, `LlrpSdk.Extensions.Impinj`,
  `LlrpSdk.Extensions.Zebra`, and `LlrpDevice.Virtual.Hosting` are published at
  version `2.0.3`.

## Verification

- Release build and automated tests are required to pass in the release workflow
  before the package is published.
- Physical-reader verification remains subject to the available hardware and is
  recorded separately in the reader interoperability evidence.
